# Правила оформления и работы над курсовой и дипломной работой

## Правила оформления и работы над курсовой работой:

### 1. Общие правила оформления текста:
- Использовать кавычки-елочки («») вместо прямых кавычек ("")
- Сохранять академический стиль изложения
- Избегать личных местоимений
- Использовать точные и конкретные формулировки
- Не писать заголовки/подзаголовки внутри разделов
- Запрещено заканчивать текст рисунком или таблицей: в конце подраздела должен быть текст
- Ссылка на рисунок должна идти в конце предложения (если ссылка указывается в скобках)

### 2. Правила оформления перечислений:
- Не использовать вложенные перечисления в тексте
- Каждый пункт перечисления начинается с маленькой буквы
- Все пункты кроме последнего заканчиваются точкой с запятой (;)
- Последний пункт кончается точкой

### 3. Порядок проверки и внесения изменений:
- Сначала прочитать файл с текстом
- Затем прочитать соответствующий файл с кодом
- Сравнить описание в тексте с реальной реализацией
- При обнаружении несоответствий внести изменения в текст
- Проверить внесенные изменения на соответствие правилам оформления

### 4. Правила работы с кодом:
- Всегда проверять реальную структуру и функционал
- Описывать только существующие элементы и функции
- Использовать точные названия переменных, функций и классов
- Сверять описание с актуальной версией кода

### 5. Язык и стиль:
- Все ответы и тексты должны быть на русском языке
- Использовать профессиональную терминологию
- Соблюдать единый стиль описания во всех разделах
- Избегать разговорных выражений

### 6. Структура описания интерфейса:
- Сначала описывать общую структуру страницы/компонента
- Затем перечислять основные элементы
- Описывать функциональные возможности
- Указывать особенности реализации
- Завершать описание указанием на соответствующий рисунок
