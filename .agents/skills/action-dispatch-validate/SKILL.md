# /action-dispatch-validate — Валидация команд и действий 1С

Навык выполняет синтаксический и схемный контроль JSON-ответов языковой модели, формирующих прикладные действия для 1С (создание документов, открытие форм, проведение, формирование отчетов).

## Поддерживаемые типы действий 1С

1. `open_form` — открытие формы объекта или списка метаданных.
2. `create_document` — подготовка и заполнение реквизитов документа.
3. `open_report` — запуск варианта отчета с передачей параметров.
4. `create_task` — добавление задачи на канбан-доску.

## Запуск валидации

```powershell
python .agents/skills/action-dispatch-validate/scripts/validate_actions.py
```
