# /code-doc-sync — Сверка текста диплома с программным кодом

Навык выполняет статический анализ исходных файлов проектов 1С (`1c_extensions/*.bsl`) и Python-сервиса (`Middleware/app/`), сопоставляя имена процедур, функций, эндпоинтов и модулей с текстом пояснительной записки диплома.

## Возможности

- выявление устаревших ссылок (например, упоминаний `1C_Full_Code_v5.bsl` вместо `v6`);
- проверка упоминания актуальных эндпоинтов REST API (`/auth/login`, `/chat/message`, `/kanban/tasks`, `/metadata/search`);
- поиск расхождений в именовании ключевых экспортных процедур 1С.

## Запуск проверки

```powershell
python .agents/skills/code-doc-sync/scripts/check_code_sync.py
```
