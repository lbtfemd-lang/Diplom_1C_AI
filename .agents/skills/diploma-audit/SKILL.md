# /diploma-audit — Аудит текста глав диплома

Навык выполняет автоматическую проверку файлов пояснительной записки диплома на соответствие строгим правилам оформления и академического стиля.

## Проверяемые правила

1. **Кавычки:** Использование кавычек-елочек («») вместо прямых ("").
2. **Перечисления:** Каждый пункт начинается с маленькой буквы, заканчивается точкой с запятой (;), а последний пункт — точкой. Отсутствие вложенных перечислений.
3. **Ссылки на иллюстрации:** Ссылка на рисунок в скобках `(рисунок X.Y)` должна располагаться в конце предложения.
4. **Завершение разделов:** Запрещено заканчивать подраздел рисунком или таблицей — в конце обязательно должен быть завершающий текст.
5. **Академический стиль:** Исключение личных местоимений («я», «мы», «наш», «мой»).

## Запуск проверки

```powershell
# Проверка конкретного файла главы
python .agents/skills/diploma-audit/scripts/audit_diploma.py text/00_Введение_рерайт.md

# Проверка всех глав диплома в каталоге text/
python .agents/skills/diploma-audit/scripts/audit_diploma.py text/
```
