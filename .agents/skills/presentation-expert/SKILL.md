# /presentation-expert — Эксперт по созданию и валидации конкурсных презентаций

Навык предоставляет агенту Codex полный инструментарий для генерации, программной сборки через `python-pptx`, визуального тюнинга и инженерного аудита слайдовых презентаций высшего класса.

---

## 1. Когда использовать данный навык
- Создание новой презентации по мастер-промпту ([text/МАСТЕР_ПРОМПТ_ДЛЯ_ПРЕЗЕНТАЦИИ.md](../../text/МАСТЕР_ПРОМПТ_ДЛЯ_ПРЕЗЕНТАЦИИ.md)).
- Программная компиляция `.pptx` файла в широкоформатном разрешении 16:9.
- Точечная модификация существующих слайдов (добавление карточек, таблиц, изменение цветовых схем).
- Валидация презентаций на переполнение текста, контрастность, читаемость и соответствие инженерным фактам диплома.
- Подготовка промптов для внешних генераторов слайдов (Gamma.app, Claude Artifacts, Beautiful.ai).

## 2. Архитектура визуального стиля (Modern Dark Enterprise)

Слайды собираются по модульной сетке 16:9 ($13.333'' \times 7.5''$):
- **Фон слайда:** сплошной темный сланец `#0F172A` (`RGBColor(15, 23, 42)`);
- **Подложка карточек:** скругленные прямоугольники `#1E293B` (`RGBColor(30, 41, 59)`) с границей `#334155` толщиной 1 pt;
- **Акцент 1С:** янтарно-золотой `#FFB300` (`RGBColor(255, 179, 0)`) для метрик, иконок и стрелок;
- **Технический акцент:** неоновый циан `#06B6D4` (`RGBColor(6, 182, 212)`) для RAG, векторов и схем интеграции;
- **Индикаторы статуса:** зеленый `#10B981` (успех), красный `#EF4444` (стоп-факторы, DoS, 115-ФЗ).

Все токены стилей зафиксированы в: [resources/design_tokens.json](./resources/design_tokens.json).

## 3. Программная генерация слайдов через `python-pptx`

В составе навыка поставляется автономный скрипт автоматической сборки полной презентации на 18 слайдов:
```bash
python .agents/skills/presentation-expert/scripts/build_pptx_deck.py
```
Скрипт формирует готовый файл `release/Интеллектуальный_ассистент_для_1С_УНФ_КОНКУРС.pptx` с полной компоновкой, таблицами, карточками и встроенными заметками докладчика.

### Базовые шаблоны компоновки (Layouts):
1. **Title Layout:** центрированный блок с фирменным бейджем 1С, реквизитами автора и руководителя.
2. **3-Card Grid:** три равные карточки с иконками, заголовками золотом и буллетами (идеально для проблем, аналогов, архитектурных слоев).
3. **2x3 Grid:** шесть компактных карточек с бейджами (для 6 прикладных бизнес-сервисов РФ).
4. **Metric Callout (Hero):** огромный моноширинный бейдж (48 pt) по центру или слева, поясняющий текст и сравнительный мини-график справа.
5. **Comparison Matrix:** стилизованная таблица со столбцами «Критерий / Аналог 1 / Наша разработка» с цветовым выделением преимуществ.
6. **Split 50/50:** левая половина — схема потока/планировка, правая — таблица замеров или перечень инженерных решений.

## 4. Автоматический аудит и контроль качества презентации

Для проверки готовой презентации запускается скрипт валидации:
```bash
python .agents/skills/presentation-expert/scripts/validate_deck.py <путь_к_файлу.pptx>
```
Скрипт проверяет:
- точное количество слайдов (ровно 18);
- соотношение сторон (строго 16:9);
- наличие и полноту заметок спикера на каждом слайде;
- отсутствие недопустимых плейсхолдеров (`Lorem Ipsum`, `[График]`, `TODO`);
- наличие ключевых верифицированных метрик (62 теста, 945.6 RPS, 1.06 мс, 150 WAL, 115-ФЗ).
