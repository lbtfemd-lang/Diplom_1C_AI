# /rag-optimize — Оптимизация RAG по метаданным 1С

Навык предоставляет алгоритмы гибридного поиска (Hybrid Search = BM25 + Cosine Similarity) и инструменты тестирования релевантности поиска релевантных объектов среди 16 577 элементов метаданных конфигурации 1С:УНФ.

## Запуск бенчмарка RAG

```powershell
python .agents/skills/rag-optimize/scripts/test_rag.py "остатки номенклатуры на складах"
```
