# /report-builder — Генератор технических отчетов

Навык предоставляет унифицированные шаблоны и правила составления отчетов о развертывании, протоколов тестирования и аудитов архитектуры.

## Структура типовых отчетов

1. **Протокол тестирования:** фиксация прогона модульных и интеграционных тестов (Pytest, Vanessa Automation), времени отклика и покрытия.
2. **Отчет по развертыванию:** пошаговая фиксация шагов установки Middleware, настройки конфигурации 1С и проверки сетевого взаимодействия.
3. **Отчет по аудиту кода:** инвентаризация артефактов, список неиспользуемых файлов, анализ технического долга.

Шаблоны доступны в: [report_templates.md](./resources/report_templates.md).
