# Приложение А — Структура и сигнатуры модулей клиентской части (1С:Предприятие)

В данном приложении приведено детальное описание структуры, интерфейсных процедур и функций расширения «Интеллектуальный ассистент» для конфигурации «1С:Управление нашей фирмой 3.0», содержащихся в основном модуле формы чата `1C_Full_Code_v6.bsl`.

## А.1 Общая структура и назначение ключевых процедур и функций

| Имя процедуры/функции | Среда исполнения | Описание и назначение |
| :--- | :--- | :--- |
| `ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)` | На Сервере | Выполняет инициализацию параметров подключения к middleware (адрес, логин, пароль) и считывает сохраненный токен авторизации. |
| `ПриОткрытии(Отказ)` | На Клиенте | Запускает процесс первичной авторизации и отрисовки окна чата. |
| `СгенерироватьЧатHTML()` | На Сервере | Генерирует адаптивный HTML/CSS код для отображения сообщений в чате. Форматирует бабблы, аватары, Action Chips и временные метки. |
| `СгенерироватьЧатHTMLЗагрузка()` | На Сервере | Формирует временную HTML-структуру с CSS-анимацией трех точек для индикации ожидания ответа от языковой модели. |
| `ПреобразоватьMarkdownВHTML(ИсходныйТекст)` | На Сервере Без Контекста | Преобразует Markdown-разметку ответа LLM (`**жирный**`, `*курсив*`, `- списки`, `<code>код</code>`) в безопасный HTML. |
| `СформироватьActionChipsHTML(Действие, ДанныеJSON)` | На Сервере Без Контекста | Формирует кликабельные кнопки быстрых действий (Action Chips) под ответом ассистента. |
| `ОтправитьСообщение(Команда)` | На Клиенте | Обрабатывает ввод сообщения пользователем, очищает текстовое поле, выводит индикатор загрузки и инициирует асинхронный HTTP-запрос к middleware. |
| `ВыполнитьКомандуАссистента(Действие, Данные)` | На Клиенте | Диспетчер команд (Action Dispatcher). Считывает имя команды (`action`) и параметры (`data`), проверяет их на безопасность и выполняет нативные вызовы 1С. |
| `Шаг1_ПроверкаКлиента(Контекст)` | На Клиенте | Первая фаза универсального мастера создания документов. Выполняет поиск контрагента в базе по переданному тексту. |
| `ПослеОтветаОКлиенте(Результат, Контекст)` | На Клиенте | Обрабатывает выбор пользователя при предложении создать нового контрагента. |
| `Шаг2_ПроверкаТовара(Контекст)` | На Клиенте | Вторая фаза универсального мастера создания документов. Выполняет поиск номенклатуры на складе. |
| `ПослеОтветаОТоваре(Результат, Контекст)` | На Клиенте | Обрабатывает выбор пользователя при предложении создать новую номенклатуру. |
| `Шаг3_Финал(Контекст)` | На Клиенте | Завершающая фаза мастера создания документов. Заполняет реквизиты нового документа (Заказ, Накладная, Платеж) и открывает форму на экране. |
| `ПолучитьОстаткиТовараНаСервере(ТоварИмя)` | На Сервере | Выполняет прямой запрос к регистру «Запасы» УНФ с группировкой остатков по складам. |
| `ПолучитьСписокДолжниковНаСервере()` | На Сервере | Формирует структурированную сводку по дебиторской и кредиторской задолженности. |
| `СобратьДосьеНаСервере(ТипОбъекта, ИмяОбъекта)` | На Сервере | Формирует сводное досье партнера (ИНН, последний заказ, контактная информация). |
| `ВыполнитьАналитикуНаСервере(Вопрос)` | На Сервере | Выполняет оперативный расчет объема продаж и закупок за день, неделю, месяц или год. |
| `СобратьМетаданныеНаСервере()` | На Сервере | Обходит структуру конфигурации (справочники, документы, отчеты, регистры), собирает их имена и синонимы, после чего отправляет JSON-пакет на middleware для перестройки RAG-индекса. |
| `НастройкиПодключенияНажатие(Элемент)` | На Клиенте | Открывает интерактивный диалог настройки URL-адреса сервера Middleware. |
| `БезопасноОткрытьФорму(ИмяФормы, Описание, Параметры)` | На Клиенте | Выполняет защищенное открытие нативных форм списков или объектов 1С с обработкой ошибок. |

## А.2 Служебная библиотека сетевого взаимодействия (Префикс «Ш_»)

- `Процедура ШПолучитьТокенАвторизации()`: Запрашивает и сохраняет JWT-токен в контексте сеанса.
- `Функция ШЗаголовкиСАвторизацией()`: Формирует HTTP-заголовки запроса с токеном `X-Auth-Token`.
- `Функция ШСоздатьСоединение()`: Инициализирует объект `HTTPСоединение` с учетом настроек порта и SSL.
- `Функция ШОтправитьHTTP(Путь, ТелоЗапроса, Метод)`: Низкоуровневая отправка HTTP-запроса и чтение ответа сервера.
- `Функция ШВыполнитьHTTPЗапрос(Путь, ТелоЗапроса, Метод)`: Обертка с обработкой ошибок и автоматическим перезапросом JWT-токена при 401 Unauthorized.
- `Функция ШСериализоватьВJSON(Данные)`: Преобразует структуры встроенного языка 1С в JSON-строку.
- `Функция ШДесериализоватьИзJSON(СтрокаJSON)`: Выполняет разбор входящей JSON-строки в структуры 1С.
- `Функция ШЭкранироватьHTML(Текст)`: Выполняет экранирование HTML-тегов для предотвращения XSS.
