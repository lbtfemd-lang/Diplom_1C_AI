# Приложение А — Структура и сигнатуры модулей клиентской части (1С:Предприятие)

В данном приложении приведено детальное описание структуры, интерфейсных процедур и функций расширения «Интеллектуальный ассистент» для конфигурации «1С:Управление нашей фирмой 1.6», содержащихся в модуле формы чата `1C_Full_Code_v6.bsl`.

## А.1 Общая структура и назначение ключевых процедур и функций

| Имя процедуры/функции | Среда исполнения | Описание и назначение |
| :--- | :--- | :--- |
| `ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)` | На Сервере | Выполняет инициализацию параметров подключения к middleware (адрес, логин, пароль) и считывает сохраненный токен авторизации. |
| `ПриОткрытии(Отказ)` | На Клиенте | Запускает процесс первичной отрисовки окна чата на основе накопленной истории переписки. |
| `СгенерироватьЧатHTML()` | На Сервере | Генерирует HTML/CSS код для отображения сообщений в чате. Форматирует бабблы (оранжевые для пользователя, темно-синие для ассистента) и ссылки на объекты 1С. |
| `СгенерироватьЧатHTMLЗагрузка()` | На Сервере | Формирует временную HTML-структуру с CSS-анимацией трех точек для индикации ожидания ответа от языковой модели. |
| `ПолучитьТокенАвторизацииНаСервере()` | На Сервере | Отправляет запрос на эндпоинт `/auth/login` для получения нового JWT-токена доступа при авторизации. |
| `ВыполнитьHTTPЗапрос(Путь, ТелоЗапроса, Метод)` | На Сервере | Общая обертка для отправки синхронных HTTP-запросов к API middleware. |
| `ДобавитьСообщениеВЧатНаСервере(Текст, Роль)` | На Сервере | Добавляет новую строку в табличную часть формы `ЧатИстория` и перерисовывает HTML-контент чата. |
| `ОтправитьСообщение(Команда)` | На Клиенте | Обрабатывает ввод сообщения пользователем, очищает текстовое поле, выводит индикатор загрузки и инициирует асинхронный HTTP-запрос к middleware. |
| `ВыполнитьКомандуАссистента(Действие, Данные)` | На Клиенте | Диспетчер команд (Whitelist). Считывает имя команды (`action`) и параметры (`data`), проверяет их на безопасность и выполняет нативные вызовы 1С. |
| `Шаг1_ПроверкаКлиента(Контекст)` | На Клиенте | Первая фаза мастера создания документов. Выполняет поиск контрагента в базе по переданному тексту. |
| `ПослеОтветаОКлиенте(Результат, Контекст)` | На Клиенте | Обрабатывает выбор пользователя при предложении создать нового контрагента. |
| `Шаг2_ПроверкаТовара(Контекст)` | На Клиенте | Вторая фаза мастера создания документов. Выполняет поиск номенклатуры на складе. |
| `Шаг3_Финал(Контекст)` | На Клиенте | Завершающая фаза мастера создания документов. Заполняет реквизиты нового документа «Заказ покупателя» и открывает его форму на экране. |
| `СобратьМетаданныеНаСервере()` | На Сервере | Обходит структуру конфигурации (справочники, документы, отчеты), собирает их имена и синонимы, после чего отправляет JSON-пакет на middleware для перестройки RAG-индекса. |
| `ЭтоМобильныйКлиент()` | На Клиенте | Проверяет системные параметры окружения и определяет, запущено ли приложение в мобильном клиенте 1С. |
| `БезопасноОткрытьФорму(ИмяФормы, Описание, Параметры)` | На Клиенте | Выполняет защищенное открытие нативных форм списков или объектов 1С. |

## А.2 Библиотека сетевого взаимодействия (Префикс «Ш_»)

Для совместимости со старыми версиями платформы и обеспечения отказоустойчивости в модуле выделен служебный блок процедур и функций низкоуровневого HTTP-взаимодействия:

- `Функция ШАдресСервера()`: Возвращает базовый URL-адрес сервера middleware.
- `Функция ШЛогинСервисногоАккаунта()` / `ШПарольСервисногоАккаунта()`: Хранят параметры авторизации сервисного аккаунта 1С.
- `Процедура ШПолучитьТокенАвторизации()`: Запрашивает и сохраняет JWT-токен во временном хранилище сеанса.
- `Функция ШЗаголовкиСАвторизацией()`: Формирует HTTP-заголовки запроса, прикрепляя JWT-токен в заголовок `X-Auth-Token`.
- `Функция ШСоздатьСоединение()`: Инициализирует объект `HTTPСоединение` с учетом настроек прокси и протокола HTTPS.
- `Функция ШОтправитьHTTP(Путь, ТелоЗапроса, Метод)`: Низкоуровневая отправка HTTP-запроса и чтение ответа сервера.
- `Функция ШВыполнитьHTTPЗапрос(Путь, ТелоЗапроса, Метод)`: Обертка с обработкой ошибок и автоматическим перезапросом JWT-токена в случае получения ошибки 401 (Unauthorized).
- `Функция ШСериализоватьВJSON(Данные)`: Преобразует структуры встроенного языка 1С в JSON-строку.
- `Функция ШДесериализоватьИзJSON(СтрокаJSON)`: Выполняет разбор входящей JSON-строки в структуры и соответствия 1С.
- `Функция ШЭкранироватьHTML(Текст)`: Выполняет замену спецсимволов HTML-тегов для предотвращения XSS-инъекций в окне чата.
