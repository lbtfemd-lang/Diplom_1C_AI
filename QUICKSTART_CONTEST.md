# Инструкция по быстрому запуску для жюри Всероссийского конкурса «1С»

> **Номинация:** «Лучший инновационный проект с использованием передовых технологий (ИИ/Интеграции)»  
> **Тема:** Интеллектуальный ассистент на базе искусственного интеллекта и омниканальной архитектуры для типовой конфигурации «1С:Управление нашей фирмой 3.0»  
> **Время развертывания:** **1 минута в 1 клик**

---

## 🚀 Вариант 1: Экспресс-запуск стенда в 1 клик (Рекомендуемый)

На компьютере под управлением ОС Windows с установленным Python 3.10+:

1. Запустите двойным кликом файл **`run_demo.bat`** в корне репозитория.
2. Скрипт в автоматическом режиме:
   * Проверит окружение;
   * Создаст локальный `.venv` и доустановит зависимости;
   * Сгенерирует безопасную демо-конфигурацию базы данных SQLite;
   * Наполнит базу тестовыми пользователями и ролями;
   * **Автоматически откроет браузер** по адресу: **`http://localhost:8000`**.

> [!NOTE]
> **Автономный оффлайн-режим (Zero-Cloud Mode):**  
> Проект полностью функционален даже на закрытом изолированном стенде без интернета и без указания платных API-ключей. Встроенный гибридный движок автоматически переключается на локальный детерминированный RAG и выдает аутентичные виджеты и калькуляторы 1С.

---

## 🐳 Вариант 2: Запуск в контейнере Docker

Если на демонстрационном компьютере установлен Docker Desktop:
```bash
docker compose up -d
```
После этого откройте в браузере: `http://localhost:8000`.

## 🧭 Пошаговый сценарий демонстрации (Step-by-Step)

### Сценарий 1: Проверка финансового комплаенса (115-ФЗ)
1. В верхнем меню перейдите в раздел **«Бизнес-инструменты РФ»** -> вкладка **«🛡 115-ФЗ и Контрагенты»**.
2. Введите ИНН контрагента `7707083893` или оставьте тестовый, нажмите кнопку **«Проверить»**.
3. Система выполнит проверку контрольных сумм алгоритмом ФНС, сопоставит со стоп-факторами и выдаст вердикт надежности.
4. Во второй форме введите сумму платежа `590000` руб. и назначение «Выдача денежных средств: беспроцентный заем учредителю без НДС». Нажмите **«Проверить 115-ФЗ»** — система мгновенно классифицирует операцию по порогам Росфинмониторинга.

### Сценарий 2: Защита маржинальности сделки
1. Откройте подвкладку **«📈 Защита маржи»**.
2. Укажите сумму сделки `92` руб. при себестоимости `80` руб. (наценка 15%) или скорректируйте скидку.
3. Нажмите **«Рассчитать юнит-экономику сделки»**. При нарушении порога рентабельности (<15%) система заблокирует сделку и автоматически сформирует задачу на утверждение скидки директору в Канбан-доске!

### Сценарий 3: Взыскание задолженности по ст. 395 ГК РФ
1. Откройте подвкладку **«⚖️ Пени ст. 395 ГК РФ»**.
2. Нажмите **«Рассчитать проценты по ст. 395»** — система автоматически учтет действующие ключевые ставки Банка России (21%) по периодам просрочки.
3. Нажмите **«Сформировать досудебную претензию»** — система сформирует официальный юридический текст досудебной претензии и отправит его на электронную почту должника (в sandbox Outbox).

### Сценарий 4: Умный автозаказ ROP/EOQ
1. Перейдите во вкладку **«📦 Автозаказ ROP/EOQ»**.
2. Нажмите **«Запустить расчет складского баланса»** — алгоритм на основе формулы Уилсона рассчитает экономичный размер партии и точки перезаказа (ROP).
3. Кнопка **«Скопировать JSON 1C»** позволяет в 1 клик передать готовый черновик документа в 1С (`Документ.ЗаказПоставщику`).

### Сценарий 5: Распознавание накладных и счетов (OCR)
1. Перейдите во вкладку **«📄 OCR счетов и УПД»**.
2. Нажмите кнопку **«Вставить образец счета»** (или вставьте скан/текст любого счета на оплату).
3. Нажмите **«Распознать и сопоставить с 1С»** — алгоритм нечеткого сопоставления (Левенштейн) найдет совпадения в номенклатурном справочнике 1С и проверит арифметику НДС.

### Сценарий 6: Диалог с ИИ на естественном языке
1. Перейдите в раздел **«Ассистент 1С»** (вкладка «Чат»).
2. Нажмите на быстрые кнопки-подсказки или напишите текстом:
   * *«Какой у нас кассовый разрыв?»* — система отобразит интерактивный прогноз платежного календаря на 7 дней.
   * *«Кто из клиентов просрочил оплату больше всего?»* — карточки должников из регистра 1С.
   * *«Поставь задачу проверить склад к пятнице»* — мгновенное создание поручения в Канбан 1С.

## 💾 Подключение к 1С:Предприятие (2 варианта)

### Вариант 1: Полная демо-база с данными (Рекомендуемый)
* В корне проекта размещен файл **`Diplom_28.05.dt`** (1,3 ГБ) — наполненная база «1С:УНФ 3.0» с демонстрационными документами и предустановленным ассистентом.
* Создайте пустую базу в стартере 1С и выполните: **«Администрирование» → «Загрузить информационную базу...»**, указав файл `Diplom_28.05.dt`.

### Вариант 2: Внедрение расширения CFE в существующую базу УНФ (Вариант Б)
* **Файл:** `1c_extensions/AIAssistant.cfe` (готовое расширение для интеграции).
* **Порядок установки:**
  1. В Конфигураторе 1С: **«Конфигурация»** → **«Расширения конфигурации»** → **«Действия»** → **«Загрузить конфигурацию из файла...»** (`1c_extensions/AIAssistant.cfe`).
  2. **Снять галочки:** ❌ «Безопасный режим» и ❌ «Защита от опасных действий» (разрешает сетевой обмен с Middleware).
  3. **Совместимость версий:** Если платформа 8.3 (8.3.20–8.3.25), в свойствах расширения (`F4`) установите «Режим совместимости» равным режиму основной конфигурации (или «Не использовать»).
  4. Нажмите **F7** («Обновить конфигурацию базы данных»).

> [!TIP]
> **Автономный запуск без Конфигуратора:** В папке `1c_extensions/` также находятся внешние обработки `ЧатСАссистентом.epf` и `КанбанДоска.epf`, которые открываются через «Файл → Открыть» на любой версии платформы 8.3 / 8.5 мгновенно без каких-либо настроек.
