# Интеллектуальный ассистент для 1С:УНФ

Дипломный проект объединяет чат-ассистента в 1С:УНФ, RAG-поиск по метаданным конфигурации и канбан-доску. Пользователь работает в интерфейсе 1С, а отдельный Python-сервис отвечает за авторизацию, обращение к языковой модели, хранение задач и поиск подходящих объектов метаданных.

## Состояние проекта

- Платформа: 1С:Предприятие 8.3, конфигурация «Управление нашей фирмой» 8.5.1.1150.
- Middleware: Python 3.12, FastAPI, SQLAlchemy и SQLite.
- LLM: Fireworks AI / GLM 5.1; резервный провайдер — OpenRouter / Qwen 2.5 72B.
- RAG: `paraphrase-multilingual-MiniLM-L12-v2`; для полноценного поиска требуется установленный `sentence-transformers` или согласованный предвычисленный индекс.
- Канбан: четыре колонки, четыре приоритета, роли и разграничение доступа по подразделениям.
- Автотесты: 46 тестов middleware проходят на текущем состоянии репозитория (проверено 30 августа 2026 года).

## Быстрый запуск

Требуются Python 3.12 и доступ к Fireworks AI или OpenRouter.

```powershell
cd Middleware
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` необходимо задать как минимум один LLM API-ключ и постоянный `JWT_SECRET`. После этого:

```powershell
.venv\Scripts\python.exe main.py
```

Проверка состояния: `http://127.0.0.1:8000/health`. Интерактивная схема API доступна по адресу `http://127.0.0.1:8000/docs`.

Для локальной демонстрации при первом запуске автоматически создаются тестовые пользователи и подразделения. Встроенные пароли предназначены только для стенда; перед публикацией или сетевым развёртыванием их следует заменить.

Установка форм 1С описана в [руководстве по настройке](docs/SETUP_GUIDE.md) и [пошаговой инструкции](docs/STEP_BY_STEP_1C.md).

## Структура репозитория

| Путь | Назначение | Статус |
|---|---|---|
| `Middleware/` | FastAPI-приложение, модели, сервисы и тесты | исходный код |
| `1c_extensions/` | модули форм двух расширений 1С и общий HTTP-фрагмент | исходный код |
| `docs/` | актуальная техническая и пользовательская документация | исходный материал |
| `text/` | главы диплома, рисунки, сборщик DOCX и материалы защиты | рабочие материалы |
| `release/` | собранный демонстрационный комплект | снимок релиза; вручную не синхронизируется |
| `config_unpacked/` | распакованная конфигурация УНФ | производный исследовательский артефакт |
| `src/` | промежуточные результаты распаковки DT/CF | производные и диагностические файлы |
| `step_by_step/` | расширенные черновые инструкции установки | вспомогательная документация |
| `assemble_diploma.py` | сборка Markdown из шести актуальных глав `_рерайт` | инструмент сборки |
| `unpack_config.py` | распаковка конфигурации через Designer | служебный инструмент |

Полная карта и правила выбора актуальных файлов: [структура и артефакты](docs/PROJECT_STRUCTURE.md).

## Основные возможности

- консультации по методологии работы в 1С:УНФ;
- поиск и открытие объектов, подготовка документов и запуск прикладных действий в 1С;
- запрос остатков, статусов, должников и аналитики;
- создание канбан-задач из чата;
- канбан-доска с фильтрацией, статистикой, уведомлениями, экспортом CSV и обменом с 1С;
- загрузка метаданных конфигурации и добавление релевантных объектов в контекст LLM;
- JWT-авторизация и роли `admin`, `manager`, `employee`.

## Важные ограничения перед конкурсной публикацией

- Встроенные демонстрационные учётные записи создаются с известными паролями.
- Обмен между 1С и middleware по умолчанию настроен на локальный HTTP `127.0.0.1:8000`.
- SQLite-файл и индекс метаданных привязаны к рабочему каталогу процесса; Docker volume в текущем `docker-compose.yml` не сохраняет эти файлы в `/app/data`.
- Заявленный лексический fallback RAG сейчас не срабатывает при отсутствии embeddings из-за раннего выхода в `MetadataService`; облегчённая Docker-сборка фактически работает без RAG-кандидатов.
- Каталог `release/` содержит снимок, который может отставать от корневых исходников.
- Техническая документация описывает фактическую реализацию, но ручная проверка модулей BSL в Конфигураторе 1С всё ещё обязательна.
