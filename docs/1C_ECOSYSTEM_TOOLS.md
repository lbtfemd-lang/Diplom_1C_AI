# Справочник открытых инструментов экосистемы «1С:Предприятие» (GitHub)

В данном документе систематизированы наиболее востребованные и эффективные открытые инструменты разработки, статического анализа, автоматизированного тестирования и CI/CD для платформы «1С:Предприятие 8.3».

---

## 1. Статический анализ и контроль качества кода

### 1.1. BSL Language Server
- **Репозиторий:** `github.com/1c-syntax/bsl-language-server`
- **Назначение:** Языковой сервер протокола LSP для языков BSL и OneScript.
- **Возможности:**
  - обнаружение более 200 видов потенциальных ошибок, уязвимостей и антипаттернов;
  - контроль цикломатической и когнитивной сложности процедур и функций;
  - проверка соответствия стандартам разработки фирмы «1С» (ИТС);
  - интеграция с VS Code, Antigravity, Eclipse (EDT) и CI/CD.
- **Установка:** Загрузка исполняемого jar-пакета или npm-пакета `bsl-language-server`.

### 1.2. SonarQube BSL Plugin
- **Репозиторий:** `github.com/1c-syntax/sonar-bsl-plugin-community`
- **Назначение:** Плагин для платформы непрерывного анализа SonarQube.
- **Возможности:** Формирование отчетов по техническому долгу, покрытию тестами и динамике качества кода при каждом коммите.

---

## 2. Автоматизация сценариев и среда выполнения (OneScript)

### 2.1. OneScript (`oscript`)
- **Репозиторий:** `github.com/EvilBeaver/OneScript`
- **Назначение:** Кроссплатформенная среда исполнения сценариев на встроенном языке 1С без использования платформы «1С:Предприятие».
- **Возможности:**
  - написание утилит администрирования, сборки и выгрузки данных на знакомом синтаксисе BSL;
  - поддержка менеджера пакетов `opm` (`opm install <библиотека>`).

### 2.2. v8runner
- **Репозиторий:** `github.com/oscript-library/v8runner`
- **Назначение:** Утилита командной строки OneScript для запуска и управления конфигуратором 1С.
- **Возможности:**
  - пакетное создание файловых и серверных информационных баз;
  - выгрузка и загрузка конфигураций (`.cf`, `.cfe`) и данных (`.dt`, `.xml`);
  - запуск обновления конфигурации базы данных в пакетном режиме с разбором кодов возврата и лог-файлов.

### 2.3. gitsync
- **Репозиторий:** `github.com/oscript-library/gitsync`
- **Назначение:** Инструмент синхронизации исходных кодов конфигураций 1С с репозиториями Git.
- **Возможности:** Автоматический перенос коммитов из хранилища 1С в Git с сохранением авторства и комментариев к версиям.

## 3. Автоматизированное тестирование

### 3.1. Vanessa Automation
- **Репозиторий:** `github.com/silverbulleters/vanessa-automation`
- **Назначение:** Фреймворк для BDD-тестирования (поведенческого тестирования) прикладных решений 1С.
- **Возможности:**
  - написание сценариев тестирования пользовательского интерфейса на естественном русском языке (Gherkin);
  - автоматический прогон кликов, заполнения реквизитов, проведения документов и проверки экранных форм;
  - генерация скриншотов и видеозаписей при падении сценариев.

### 3.2. YAxUnit (xUnit for 1C)
- **Репозиторий:** `github.com/oscript-library/yaxunit`
- **Назначение:** Фреймворк модульного (Unit) тестирования для конфигураций 1С и OneScript.
- **Возможности:** Написание и изолированное выполнение тестов серверных методов и функций с генерацией отчетов в формате JUnit/Allure.

---

## 4. Низкоуровневая декомпиляция и работа с контейнерами

### 4.1. v8reader / v8unpack
- **Репозиторий:** `github.com/1c-syntax/v8-reader`
- **Назначение:** Утилиты для прямого чтения и распаковки бинарных контейнеров 1С (`.cf`, `.epf`, `.erf`, `.cfe`) без запуска толстого клиента или конфигуратора платформы.
- **Возможности:** Быстрое извлечение модулей, табличных документов и XML-структуры объектов метаданных.
