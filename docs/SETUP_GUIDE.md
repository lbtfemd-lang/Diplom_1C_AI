# Инструкция по установке и запуску ИИ-ассистента 1С

## Что входит в решение

| Компонент | Статус | Описание |
|-----------|--------|----------|
| Middleware (Python/FastAPI) | Готов | Сервер на 127.0.0.1:8000: чат, авторизация, RAG, канбан |
| Расширение «Интеллектуальный ассистент» | Готов | HTML-чат с пузырьковыми сообщениями + быстрые кнопки |
| Расширение «Канбан-доска» | Готов | Отдельная обработка с интерактивной HTML-доской |
| Мобильное приложение (1С) | В планах | Полноценное мобильное приложение с обоими расширениями |

## Шаг 1. Настройка Middleware (Python)

### 1.1 Установить Python 3.12

**Вариант А** — через командную строку (рекомендуется):
```
winget install Python.Python.3.12
```

**Вариант Б** — скачать с https://python.org , при установке поставить галочку **Add to PATH**.

После установки **перезапустить** командную строку и проверить:
```
python --version
```
Должно показать `Python 3.12.x`.

### 1.2 Создать виртуальное окружение

```
cd Desktop\diplom\Middleware
python -m venv venv
```

> Если папка `venv` уже существует и была создана на другом компьютере — удалить её и пересоздать.

### 1.3 Установить зависимости

**Полный набор** (с ML-моделями для качественного RAG):
```
venv\Scripts\pip install -r requirements.txt
```

> PyTorch весит ~2 ГБ, установка может занять 5-10 минут. Это нормально.

**Облегчённый набор** (без ML, fallback на word-overlap):
```
venv\Scripts\pip install -r requirements-server.txt
```

### 1.4 Настроить .env

Файл `.env` уже создан и содержит ключи. Проверить содержимое:

```
FIREWORKS_API_KEY=fw_ваш_ключ
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
JWT_SECRET=случайная_строка
JWT_ALGORITHM=HS256
JWT_EXPIRE_HOURS=24
MIDDLEWARE_HOST=127.0.0.1
MIDDLEWARE_PORT=8000
```

- **FIREWORKS_API_KEY** — получить на https://fireworks.ai → Account → API Keys
- **OPENROUTER_API_KEY** — запасной провайдер (используется если FIREWORKS не задан)
- **MIDDLEWARE_HOST** — `127.0.0.1` для локального доступа, `0.0.0.0` для мобильного
- Если ключи уже заполнены — ничего менять не нужно

### 1.5 Перегенерировать эмбеддинги

Если установлен полный набор (с sentence-transformers), выполнить один раз:
```
venv\Scripts\python generate_embeddings.py
```

Должно показать:
```
Loaded 1423 items from metadata_store.json
Embeddings shape: (1423, 384)
Done!
```

> Если установлен облегчённый набор — пропустить этот шаг. Будет использоваться fallback.

### 1.6 Запустить сервер

**Вариант А** — через bat-файл:
```
двойной клик на start.bat в папке diplom
```

**Вариант Б** — вручную:
```
cd Desktop\diplom\Middleware
venv\Scripts\python main.py
```

Должно появиться:
```
Using Fireworks AI (GLM 5.1)
LLM client initialized. Model: accounts/fireworks/models/glm-5p1
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.
```

Проверить: открыть в браузере http://127.0.0.1:8000/ — должен вернуть `{"status":"ok","service":"1C AI Assistant Middleware"}`.

### 1.7 Запустить тесты (опционально)

```
cd Desktop\diplom\Middleware
venv\Scripts\pip install pytest pytest-asyncio
venv\Scripts\python -m pytest tests -v
```

Должно показать: `29 passed`.

## Шаг 2. Создание расширения «Интеллектуальный ассистент»

### 2.1 Создать расширение

1. Открыть 1С:УНФ в режиме **Конфигуратор**
2. Меню → **Конфигурация** → **Расширения конфигурации**
3. Кнопка **Добавить** (плюс)
4. Заполнить:
   - **Имя**: `ИнтеллектуальныйАссистент`
   - **Синоним**: `Интеллектуальный ассистент`
   - **Назначение**: `Дополнение`
   - **Префикс**: `ИА_`
5. **Обязательно снять галочки**:
   - ❌ Безопасный режим
   - ❌ Защита от опасных действий
6. Нажать **ОК**

### 2.2 Добавить обработку

В дереве расширения (откроется отдельное окно):

1. Правой кнопкой на **Обработки** → **Добавить**
2. **Имя**: `ЧатСАссистентом`
3. Перейти на вкладку **Формы**, добавить **Основную форму**
4. Открыть форму в редакторе

### 2.3 Добавить реквизиты формы

Нажать кнопку **"Добавить реквизит"** (справа вверху, над деревом формы):

| Имя реквизита | Тип | Длина | Примечание |
|---------------|-----|-------|------------|
| ЧатHTML | Строка | 0 (неограниченная) | HTML-поле чата — **основной элемент формы** |
| ТекстСообщения | Строка | 0 (неограниченная) | Поле ввода (внизу формы) |
| ФлагЗагрузки | Булево | — | Скрытый индикатор загрузки |
| АдресMiddleware | Строка | 100 | IP-адрес сервера (по умолчанию 127.0.0.1) |

**Таблица формы** (нажать "Добавить реквизит" → выбрать тип "Таблица значений"):

| Имя таблицы | Колонки |
|-------------|---------|
| ЧатИстория | Автор (Строка, 100), Текст (Строка, 0), Время (Строка, 10), ТипСообщения (Строка, 20) |

> Таблица ЧатИстория — скрытый источник данных. Визуально чат отображается через HTML-поле.

### 2.4 Разместить элементы на форме

Перетащить из дерева реквизитов (справа) на форму (слева):

1. **ЧатHTML** → перетащить → появится HTML-поле
   - Займёт основную площадь формы
   - В свойствах: **Отображение** = **Поле HTML документа**
2. **ТекстСообщения** → перетащить → поле ввода (разместить **внизу** под HTML-полем)
3. **ФлагЗагрузки** → перетащить → флажок → **скрыть** (правой кнопкой → Скрыть)
4. **ЧатИстория** → перетащить → появится таблица → **сразу скрыть** (правой кнопкой → Скрыть)
5. **АдресMiddleware** → перетащить → поле ввода (вверху, маленькое) → **скрыть** если не нужен мобильный доступ

**Итоговый вид формы:**
```
┌──────────────────────────────────────────┐
│  [Заказы] [Канбан] [Сегодня]             │
│  [Должники] [Клиенты]    [АдресMiddleware]│
│ ┌────────────────────────────────────────┐ │
│ │                                        │ │
│ │          ЧатHTML (HTML-поле)           │ │
│ │    Пузырьковые сообщения с аватарками  │ │
│ │                                        │ │
│ └────────────────────────────────────────┘ │
│ ┌──────────────────────────┐ ┌──────────┐ │
│ │    ТекстСообщения        │ │Отправить  │ │
│ └──────────────────────────┘ └──────────┘ │
└──────────────────────────────────────────┘
   (ЧатИстория — скрыта)  (ФлагЗагрузки — скрыт)
```

### 2.5 Добавить быстрые кнопки

1. На форме (слева) правой кнопкой → **Добавить** → **Кнопка**
2. Создать 5 кнопок вверху формы, имена и текст:
   - `ЗаказыНажатие` → текст: `Заказы`
   - `КанбанНажатие` → текст: `Канбан`
   - `СегодняНажатие` → текст: `Сегодня`
   - `ДолжникиНажатие` → текст: `Должники`
   - `КлиентыНажатие` → текст: `Клиенты`
3. Для каждой кнопки: в свойствах → **Отображение** = **Только текст**

### 2.6 Добавить команду Отправить

1. На вкладке **Команды** → **Добавить команду**
2. **Имя**: `ОтправитьСообщение`
3. Перетащить на форму рядом с полем ТекстСообщения
4. Текст кнопки: `Отправить`

### 2.7 Вставить код

1. Перейти на вкладку **Модуль** формы
2. **Удалить весь код** который там есть
3. Открыть файл `1c_extensions/1C_Full_Code_v6.bsl` (из корня репозитория) в текстовом редакторе (Notepad++, VS Code — **не Блокнот!**)
4. **Скопировать всё содержимое** и вставить в модуль формы
5. Нажать **Ctrl+S** (сохранить)

### 2.8 Проверить компиляцию

Нажать **F8** (проверка). Ошибок быть не должно.

Если ругается на неизвестные имена — проверить что реквизиты названы **точно**: `ЧатИстория`, `ТекстСообщения`, `ФлагЗагрузки`, `ЧатHTML`, `АдресMiddleware`.

## Шаг 5. Проверка работы

В поле ввода набрать и нажать «Отправить»:

| Запрос | Что должно произойти |
|--------|---------------------|
| Привет | Ассистент ответит приветствием в HTML-чате |
| Покажи мои заказы | Откроется список заказов |
| Покажи канбан доску | Откроется отдельная форма канбан-доски |
| Создай задачу: подготовить отчёт | Задача появится на канбан-доске |
| Список должников | В чате появится таблица должников |
| Продажи за сегодня | Аналитика по продажам |

**Как выглядит чат:**
- Сообщения пользователя — оранжевые пузырьки справа, аватарка «В»
- Ответы бота — тёмные пузырьки слева, аватарка «AI»
- Пока бот думает — анимация «три точки»
- Автопрокрутка к новому сообщению

## Как работают два расширения вместе

```
Пользователь
    ↓ вводит запрос
ЧатСАссистент (расширение 1)
    ↓ отображает в HTML-чате
    ↓ отправляет в middleware
Middleware (Python)
    ↓ LLM (Fireworks AI / GLM 5.1) + RAG (эмбеддинги)
    ↓ возвращает action + data
ЧатСАссистент
    ↓ если action = show_kanban
    ↓ открывает форму
КанбанДоска (расширение 2)
    ↓ загружает задачи из middleware
    ↓ отображает интерактивную HTML-доску
```

Оба расширения обращаются к **одному и тому же** middleware (127.0.0.1:8000) и **одной и той же** базе SQLite. Поэтому задачи созданные через чат появляются на канбан-доске и наоборот.

Если канбан-расширение не установлено — чат выведет сообщение об ошибке.

## Мобильный клиент 1С

### Что уже работает

HTML-чат, быстрые кнопки и HTTP-запросы работают в мобильном клиенте 1С без изменений. Канбан-доска автоматически открывает мобильную форму с нативной таблицей задач (вместо HTML).

### Настройка для мобильного клиента

1. **Адрес middleware**: на форме чата и канбан есть реквизит «АдресMiddleware» — ввести IP-адрес компьютера с middleware (например `192.168.1.100`). По умолчанию: `127.0.0.1` (только десктоп)

2. **Middleware должен слушать сеть**: в файле `.env` изменить:
   ```
   MIDDLEWARE_HOST=0.0.0.0
   ```

3. **Публикация базы**:
   - Установить Apache или IIS на компьютер с 1С
   - Запустить утилиту `webinst` (из комплекта платформы 1С):
     ```
     webinst -apache24 -wsdir Univ8 -dir "C:\inetpub\Univ8" -connstr "File="C:\path\to\base""
     ```
   - В мобильном клиенте 1С на телефоне подключиться к: `http://IP-СЕРВЕРА/Univ8`

4. **Ограничения мобильного клиента**:
   - Формы документов (заказы, накладные) могут отсутствовать — бот выведет предупреждение
   - HTML-поля не интерактивны — канбан автоматически открывает нативную форму
   - `ПоказатьПредупреждение` работает, `ПоказатьВопрос` работает

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| «Ошибка связи с сервером» | Убедиться что middleware запущен: http://127.0.0.1:8000/ |
| Ошибка `[Errno 10048]` при запуске | Порт 8000 занят. Закрыть предыдущий процесс middleware |
| Мобильный клиент не подключается | Проверить IP в АдресMiddleware, MIDDLEWARE_HOST=0.0.0.0, база опубликована |
| «Форма недоступна» в мобильном | Форма документа отсутствует в мобильном клиенте — это ограничение УНФ |
| «Не авторизован» | Ввести логин/пароль (admin/admin) |
| Ошибка компиляции «КонецЕсли» | Проверить что вставлен ПОЛНЫЙ код без обрезания |
| Канбан не открывается отдельно | Проверить что имя обработки = `КанбанДоска` (регистр важен) |
| HTML канбан пуст | Нажать «Обновить» на форме канбан или «Канбан» в чате |
| pip install падает | Установить Visual C++ Build Tools или `pip install --no-cache-dir` |
| sentence-transformers не ставится | Пропустить: будет использоваться fallback (word-overlap) |
| venv ссылается на другой ПК | Удалить папку venv и пересоздать: `python -m venv venv` |
| Анимация загрузки не исчезает | Проверить что реквизит `ФлагЗагрузки` добавлен и скрыт |
