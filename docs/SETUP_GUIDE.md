# Инструкция по установке и запуску ИИ-ассистента 1С

## Изолированный показ и технический комплект

Для репетиции используйте [инструкцию демо](contest/QUICKSTART_CONTEST.md): Python 3.12 с готовыми зависимостями, `run_demo.bat --check`, затем `run_demo.bat`. Лончер не удаляет окружение, не устанавливает зависимости и не читает рабочие `.env`/БД. Используется временный профиль; внешние соединения отключены. Дальнейшие разделы относятся к отдельно настраиваемому рабочему режиму, а не к изолированному демо.

`METADATA_DATA_DIR` задаёт каталог индекса метаданных; `METADATA_ML_ENABLED=false` отключает загрузку ML-модели. В чистом профиле индекс пуст. Для рабочего контура метаданные загружает администратор через `/update_metadata`.

Техническая сборка `scripts/package_contest.py` не включает локальную базу УНФ, старые EPF, диплом или презентацию. CFE собран из XML; установку в выбранную УНФ и живой сценарий необходимо проверить отдельно.

## Что входит в решение

| Компонент | Файл | Описание |
|-----------|------|----------|
| Middleware (Python/FastAPI) | `Middleware/` | Сервер 127.0.0.1:8000: чат, авторизация, RAG, канбан |
| Расширение «ИнтеллектуальныйАссистент» | `1C_Full_Code_v6.bsl` | HTML-чат + быстрые кнопки + диспетчер команд |
| Расширение «КанбанДоска» | `1C_Kanban_Extension.bsl` | HTML-доска задач |
| Мобильная форма канбана | `1C_Kanban_Mobile.bsl` | Нативная таблица задач |

## Шаг 1. Настройка Middleware (Python)

### 1.1 Установить Python 3.12

```
winget install Python.Python.3.12
```

Или скачать с https://python.org (галочка **Add to PATH**). Перезапустить терминал, проверить:

```
python --version
```

Должно показать `Python 3.12.x`.

### 1.2 Создать виртуальное окружение

```
cd Middleware
python -m venv .venv
```

> Если `.venv` уже существует от другого ПК — удалить и пересоздать.

### 1.3 Установить зависимости

**Полный набор** (с ML-моделями для качественного RAG):
```
.venv\Scripts\pip install -r requirements.txt
pip install sentence-transformers
```

> sentence-transformers + torch весят ~2-4 ГБ. Установка 5-10 мин.

**Облегчённый набор** (без ML; текущая версия запускается, но RAG-кандидаты без embeddings не формируются):
```
.venv\Scripts\pip install -r requirements-server.txt
```

### 1.4 Настроить .env

Скопировать `.env.example` в `.env` и заполнить:

```
FIREWORKS_API_KEY=fw_ваш_ключ
JWT_SECRET=случайная_строка_32_символа
JWT_ALGORITHM=HS256
JWT_EXPIRE_HOURS=24
MIDDLEWARE_HOST=127.0.0.1
MIDDLEWARE_PORT=8000
```

- **FIREWORKS_API_KEY** — получить на https://fireworks.ai → Account → API Keys
- **OPENROUTER_API_KEY** — запасной провайдер (если FIREWORKS не задан)
- **MIDDLEWARE_HOST** — `127.0.0.1` локально, `0.0.0.0` для мобильного доступа

### 1.5 Запустить сервер

**Вариант А** — через bat-файл:
```
двойной клик на start.bat в папке diplom
```

**Вариант Б** — вручную:
```
cd Middleware
.venv\Scripts\python main.py
```

Должно появиться:
```
Using Fireworks AI (GLM 5.1)
LLM client initialized. Model: accounts/fireworks/models/glm-5p1
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.
```

Проверить: http://127.0.0.1:8000/ → `{"status":"ok","service":"1C AI Assistant Middleware"}`

### 1.6 Запустить тесты (опционально)

```
cd Middleware
.venv\Scripts\python -m pytest tests --tb=short -q -p no:cacheprovider
```

Успех подтверждается завершённым прогоном без ошибок. Количество тестов меняется вместе с исходниками; используйте фактический итог pytest. Обычный набор изолирован от рабочего `.env`, использует временную БД и блокирует внешние HTTP/почтовые транспорты (см. `Middleware/README.md`).

## Шаг 2. Создание расширения «ИнтеллектуальныйАссистент»

### 2.1 Создать расширение

1. Открыть 1С:УНФ в режиме **Конфигуратор**
2. Меню → **Конфигурация** → **Расширения конфигурации**
3. Кнопка **Добавить** (плюс)
4. Заполнить:
   - **Имя**: `ИнтеллектуальныйАссистент`
   - **Синоним**: `Интеллектуальный ассистент`
   - **Назначение**: `Дополнение`
   - **Префикс**: `ИА_`
5. **ОБЯЗАТЕЛЬНО снять галочки**:
   - ❌ Безопасный режим
   - ❌ Защита от опасных действий
6. Нажать **ОК**

### 2.2 Добавить обработку

1. В дереве расширения: правой кнопкой на **Обработки** → **Добавить**
2. **Имя**: `ЧатСАссистентом`
3. Перейти на вкладку **Формы**, добавить **Основная форма**
4. Открыть форму в редакторе

### 2.3 Добавить реквизиты формы

Нажать **«Добавить реквизит»** (справа вверху, над деревом формы):

| Имя реквизита | Тип | Длина | Примечание |
|---------------|-----|-------|------------|
| ЧатHTML | Строка | 0 (неограниченная) | HTML-поле чата |
| ТекстСообщения | Строка | 0 (неограниченная) | Поле ввода |
| ФлагЗагрузки | Булево | — | Скрытый |
| АдресMiddleware | Строка | 100 | IP-адрес сервера |
| ЛогинMiddleware | Строка | 100 | по умолчанию "1c_service" |
| ПарольMiddleware | Строка | 100 | по умолчанию "1c_service_2024" |
| ИспользоватьHTTPS | Булево | — | по умолчанию Ложь |
| MiddlewareТокен | Строка | 500 | Токен авторизации |

**Таблица формы** (тип «Таблица значений»):

| Имя таблицы | Колонки |
|-------------|---------|
| ЧатИстория | Автор (Строка, 100), Текст (Строка, 0), Время (Строка, 10), ТипСообщения (Строка, 20) |

### 2.4 Разместить элементы на форме

1. **ЧатHTML** → перетащить → HTML-поле (основная площадь). В свойствах: **Отображение** = **Поле HTML документа**
2. **ТекстСообщения** → перетащить → поле ввода (**внизу**)
3. **ФлагЗагрузки** → перетащить → **СКРЫТЬ**
4. **ЧатИстория** → перетащить → таблица → **СКРЫТЬ**
5. **АдресMiddleware** → перетащить → поле ввода (вверху) → **СКРЫТЬ** если не нужен мобильный доступ

### 2.5 Добавить быстрые кнопки

Правой кнопкой на форме → **Добавить** → **Кнопка**. Создать **5 кнопок** вверху формы:

| Имя кнопки | Текст кнопки |
|------------|--------------|
| ЗаказыНажатие | Заказы |
| КанбанНажатие | 📌 Канбан |
| СегодняНажатие | 📊 Сегодня |
| ДолжникиНажатие | Должники |
| КлиентыНажатие | Клиенты |

Для каждой кнопки: в свойствах → **Отображение** = **Только текст**

### 2.6 Добавить команду «Отправить»

1. Вкладка **Команды** → **Добавить команду**
2. **Имя**: `ОтправитьСообщение`
3. Перетащить на форму рядом с полем ТекстСообщения
4. Текст кнопки: `Отправить`

### 2.7 Вставить код

1. Перейти на вкладку **Модуль** формы
2. **Удалить весь код** (Ctrl+A → Delete)
3. Открыть файл `1c_extensions/1C_Full_Code_v6.bsl` в Notepad++ или VS Code (**не Блокнот!**)
4. **Скопировать ВСЁ содержимое** и вставить в модуль формы
5. Нажать **Ctrl+S**

### 2.8 Проверить компиляцию

Нажать **F8**. Ошибок быть не должно.

Если ругается на неизвестные имена — проверить что реквизиты названы **точно**: `ЧатИстория`, `ТекстСообщения`, `ФлагЗагрузки`, `ЧатHTML`, `АдресMiddleware`.

## Архитектура: как работают расширения вместе

```
Пользователь
    ↓ вводит запрос
ЧатСАссистент (расширение 1)
    ↓ отображает в HTML-чате
    ↓ отправляет POST /chat в middleware
Middleware (Python)
    ↓ LLM + RAG → action + data
    ↓ если action = show_kanban → открыть канбан
ЧатСАссистент
    ↓ ВыполнитьКомандуАссистента()
КанбанДоска (расширение 2)
    ↓ загрузка задач из middleware
```

Оба расширения обращаются к **одному** middleware (127.0.0.1:8000) и **одной** SQLite БД.

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| «Ошибка связи с сервером» | Убедиться что middleware запущен: http://127.0.0.1:8000/ |
| Ошибка `[Errno 10048]` | Порт 8000 занят — закрыть предыдущий процесс |
| «Не авторизован» | Ввести логин/пароль (admin/admin) |
| Ошибка компиляции «КонецЕсли» | Проверить что код вставлен ПОЛНОСТЬЮ |
| Канбан не открывается | Имя обработки = `КанбанДоска` (регистр важен) |
| pip install падает | `pip install --no-cache-dir` или Visual C++ Build Tools |
| sentence-transformers не ставится | Остальные функции работают, но из-за известного дефекта RAG без embeddings не возвращает кандидатов |
| .venv от другого ПК | Удалить `.venv` и пересоздать: `python -m venv .venv` |
