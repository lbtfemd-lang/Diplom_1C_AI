# Пошаговая инструкция настройки 1С:УНФ для ИИ-ассистента

> Middleware уже запущен на http://127.0.0.1:8000/
> Платформа 1С: 8.5.1.1150 установлена в C:\Program Files\1cv8\8.5.1.1150\

---

## ШАГ 1. Создать базу УНФ

1. Запустить 1С: **Пуск** → 1С:Предприятие 8 (или `C:\Program Files\1cv8\8.5.1.1150\bin\1cv8.exe`)
2. В окне стартера нажать **«Создать»**
3. Выбрать **«Создание информационной базы из шаблона»**
4. Найти в списке: **«Управление нашей фирмой»** (smallbusiness) или **«Управление нашей фирмой, базовая»** (smallbusinessbase)
5. Ввести имя базы: `УНФ Диплом`
6. Убедиться что выбран **«Файловый режим»**
7. Путь к базе: `C:\Users\Administrator\Documents\1C\UNF_Diplom`
8. Нажать **«Готово»** → дождаться создания базы

> Если шаблона нет в списке — выбрать «Создание пустой информационной базы» → указать название.

---

## ШАГ 2. Первичный запуск УНФ

1. После создания — 1С предложит открыть базу. **Открыть в режиме 1С:Предприятие**
2. Пройти мастер первоначальной настройки УНФ (выбрать параметры организации — можно любые)
3. После завершения мастера — **закрыть** 1С

---

## ШАГ 3. Открыть базу в Конфигураторе

1. Запустить 1С стартер
2. Выбрать базу `УНФ Диплом`
3. Из выпадающего списка вместо **«1С:Предприятие»** выбрать **«Конфигуратор»**
4. Нажать **«Открыть»**

---

## ШАГ 4. Создать расширение «ИнтеллектуальныйАссистент»

### 4.1. Создать расширение

1. В Конфигураторе: меню **«Конфигурация»** → **«Расширения конфигурации»**
2. Нажать кнопку **«Добавить»** (плюс)
3. Заполнить:
   - **Имя**: `ИнтеллектуальныйАссистент`
   - **Синоним**: `Интеллектуальный ассистент`
   - **Назначение**: `Дополнение`
   - **Префикс**: `ИА_`
4. **ОБЯЗАТЕЛЬНО снять галочки:**
   - ❌ Безопасный режим
   - ❌ Защита от опасных действий
5. Нажать **ОК**

### 4.2. Добавить обработку

1. Откроется отдельное окно расширения
2. В дереве: правой кнопкой на **«Обработки»** → **«Добавить»**
3. **Имя**: `ЧатСАссистентом`
4. Перейти на вкладку **«Формы»** → нажать **«Добавить»** → **«Основная форма»**
5. Открыть форму в редакторе (двойной клик)

### 4.3. Добавить реквизиты формы

Нажать кнопку **«Добавить реквизит»** (над деревом формы, справа вверху):

| № | Имя реквизита | Тип | Длина | Примечание |
|---|---------------|-----|-------|------------|
| 1 | ЧатHTML | Строка | 0 (неограниченная) | HTML-поле чата |
| 2 | ТекстСообщения | Строка | 0 (неограниченная) | Поле ввода |
| 3 | ФлагЗагрузки | Булево | — | Скрытый |
| 4 | АдресMiddleware | Строка | 100 | IP-адрес сервера |

**Таблица формы** (кнопка «Добавить реквизит» → тип «Таблица значений»):

| Имя таблицы | Колонки |
|-------------|---------|
| ЧатИстория | Автор (Строка, 100), Текст (Строка, 0), Время (Строка, 10), ТипСообщения (Строка, 20) |

### 4.4. Разместить элементы на форме

Перетащить из дерева реквизитов (справа) на форму (слева):

1. **ЧатHTML** → перетащить → HTML-поле
   - В свойствах: **Отображение** = **Поле HTML документа**
   - Займёт основную площадь формы
2. **ТекстСообщения** → перетащить → поле ввода (разместить **ВНИЗУ** под HTML-полем)
3. **ФлагЗагрузки** → перетащить → флажок → **СКРЫТЬ** (правой кнопкой → Скрыть)
4. **ЧатИстория** → перетащить → таблица → **СКРЫТЬ** (правой кнопкой → Скрыть)
5. **АдресMiddleware** → перетащить → поле ввода (вверху, маленькое) → **СКРЫТЬ**

### 4.5. Добавить быстрые кнопки

1. На форме (слева) правой кнопкой → **«Добавить»** → **«Кнопка»**
2. Создать 5 кнопок:

| Имя кнопки | Текст кнопки |
|------------|--------------|
| ЗаказыНажатие | Заказы |
| КанбанНажатие | Канбан |
| СегодняНажатие | Сегодня |
| ДолжникиНажатие | Должники |
| КлиентыНажатие | Клиенты |

3. Для каждой кнопки: в свойствах → **Отображение** = **Только текст**

Разместить кнопки вверху формы в один ряд.

### 4.6. Добавить кнопку «Отправить»

1. Перейти на вкладку **«Команды»** → **«Добавить команду»**
2. **Имя**: `ОтправитьСообщение`
3. Перетащить команду на форму рядом с полем ТекстСообщения
4. Текст кнопки: `Отправить`

### 4.7. Вставить код

1. Перейти на вкладку **«Модуль»** формы
2. **Удалить весь код** который там есть (Ctrl+A → Delete)
3. Открыть файл `D:\Общий доступ\Проекты\diplom\1c_extensions\1C_Full_Code_v6.bsl` в Notepad++ или VS Code
4. **Скопировать ВСЁ содержимое** и вставить в модуль формы
5. Нажать **Ctrl+S** (сохранить)

### 4.8. Проверить компиляцию

Нажать **F8** (Синтакс-проверка). Ошибок быть не должно.

Если ругается на неизвестные имена — проверить что реквизиты названы **ТОЧНО**:
`ЧатИстория`, `ТекстСообщения`, `ФлагЗагрузки`, `ЧатHTML`, `АдресMiddleware`

## ШАГ 5. Создать расширение «КанбанДоска»

### 5.1. Создать второе расширение

1. Вернуться в основное окно Конфигуратора
2. Меню **«Конфигурация»** → **«Расширения конфигурации»**
3. Нажать **«Добавить»** (плюс) — это будет **ВТОРОЕ** расширение
4. Заполнить:
   - **Имя**: `КанбанДоска`
   - **Синоним**: `Канбан-доска`
   - **Назначение**: `Дополнение`
   - **Префикс**: `КД_`
5. Снять галочки:
   - ❌ Безопасный режим
   - ❌ Защита от опасных действий
6. Нажать **ОК**

### 5.2. Добавить обработку

1. В дереве расширения: правой кнопкой на **«Обработки»** → **«Добавить»**
2. **Имя**: `КанбанДоска` (именно так — чат обращается к `Обработка.КанбанДоска.Форма`)
3. Перейти на вкладку **«Формы»** → **«Добавить»** → **«Основная форма»**
4. Открыть форму в редакторе

### 5.3. Добавить реквизиты формы

| № | Имя реквизита | Тип | Длина |
|---|---------------|-----|-------|
| 1 | КанбанHTML | Строка | 0 (неограниченная) |
| 2 | АдресMiddleware | Строка | 100 |

### 5.4. Разместить элементы

1. **КанбанHTML** → перетащить на форму (займёт всю площадь)
2. В свойствах HTML-поля: **Отображение** = **Поле HTML документа**
3. **АдресMiddleware** → перетащить → поле ввода (вверху) → **СКРЫТЬ**

### 5.5. Добавить кнопки

1. Вверху формы добавить 2 кнопки:

| Имя кнопки | Текст кнопки |
|------------|--------------|
| ОбновитьНажатие | Обновить |
| СоздатьЗадачуНажатие | + Задача |

### 5.6. Вставить код

1. Перейти на вкладку **«Модуль»** формы
2. Удалить весь код
3. Скопировать содержимое файла `D:\Общий доступ\Проекты\diplom\1c_extensions\1C_Kanban_Extension.bsl`
4. Вставить в модуль формы
5. Нажать **Ctrl+S**

### 5.7. Проверить компиляцию

Нажать **F8**. Ошибок быть не должно.

## ШАГ 6. Запустить и протестировать

1. В Конфигураторе нажать **F5** (запуск в режиме 1С:Предприятие)
2. После загрузки УНФ: перейти в **«Функции для технического специалиста»**
3. Раздел **«Обработки»** → найти **«ЧатСАссистентом»** (или «Интеллектуальный ассистент»)
4. Открыть обработку
5. При первом открытии — ввести логин/пароль: **admin / admin**
6. Тестовые запросы:

| Запрос | Ожидаемый результат |
|--------|-------------------|
| Привет | Ассистент ответит приветствием |
| Покажи мои заказы | Откроется список заказов |
| Покажи канбан доску | Откроется форма канбан-доски |
| Создай задачу: подготовить отчёт | Задача появится на канбан-доске |
| Список должников | Таблица должников в чате |

---

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| «Ошибка связи с серверером» | Проверить что Middleware запущен: http://127.0.0.1:8000/ |
| «Не авторизован» | Ввести admin / admin |
| Канбан не открывается | Проверить что имя обработки = `КанбанДоска` (регистр!) |
| Ошибка компиляции | Проверить имена реквизитов, убедиться что код вставлен ПОЛНОСТЬЮ |
| HTML канбан пуст | Нажать «Обновить» на форме канбан |
| Падает при HTTP-запросе | Убедиться что безопасный режим СНЯТ в расширении |
