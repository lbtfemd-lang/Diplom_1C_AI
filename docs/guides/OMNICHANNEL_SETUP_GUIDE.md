# Руководство по настройке омниканального коммуникационного шлюза (Email, Telegram, VK)

**Граница доступа после исправлений 10.09.2026.** Входящие вебхуки требуют секрет: `TELEGRAM_WEBHOOK_SECRET` передаётся в заголовке `X-Telegram-Bot-Api-Secret-Token`, `VK_SECRET_KEY` — в поле `secret`. Без настройки сервер возвращает `503`, при несовпадении — `403`. Это правило не относится к long polling. Email-to-Order принимает JWT либо `X-Email-Hook-Secret`, совпадающий с `EMAIL_HOOK_SECRET`.

Имя отправителя, совпадение с логином и слова «директор» не предоставляют финансовых полномочий. Пока нет подтверждённой привязки внешнего аккаунта к сотруднику, его роль — `employee`; финансовые команды в реальных каналах отклоняются. Авторизованные симуляторы используют роль владельца JWT. Ниже перечислены возможности интерфейса, а не подтверждение доступа ко всем данным для любого отправителя. Для тестирования используйте изолированный pytest: обычный запуск интеграций может отправлять реальные сообщения.

Настоящее руководство предназначено для членов экспертного жюри и проверяющих конкурса дипломных проектов фирмы «1С». Интеллектуальный ассистент руководителя в системе **«1С:Управление нашей фирмой 3.0»** оснащен полнофункциональным омниканальным шлюзом, поддерживающим три ключевых канала связи:
1. **Корпоративная электронная почта (SMTP / IMAP):** автоматический робот входящих заказов (Email-to-Order), ежедневный адаптивный HTML-дайджест руководителя, претензионная работа с должниками.
2. **Telegram Bot:** интерактивные кнопки, голосовое управление, оперативные финансовые команды (`/gap`, `/orders`, `/tasks`, `/debts`).
3. **ВКонтакте Bot (Сообщество VK):** кнопочная клавиатура, прием заказов покупателей, аналитика склада и дебиторки.

## 1. Настройка корпоративной почты (Email: SMTP & IMAP)

Шлюз поддерживает работу с любым почтовым провайдером (Google Gmail, Яндекс Почта, Mail.ru, корпоративный Microsoft Exchange / Postfix).

### 1.1. Демонстрационный режим «Песочницы» (Mock Outbox Sandbox)
Если в файле конфигурации `Middleware/.env` не заданы реальные логин и пароль почтового ящика, система **автоматически работает в режиме изолированной песочницы**:
* Все формируемые письма (HTML-дайджесты, претензии, автоответы клиентам) сохраняются во внутреннем хранилище Outbox.
* Просмотреть отправленные письма с оригинальным визуальным оформлением можно в любой момент, нажав кнопку **«✉️ Почта (Outbox)»** на панели быстрых действий веб-портала или открыв вкладку **«Инфраструктура 1С»**.
* **Для защиты диплома и стендовой проверки этого режима достаточно на 100%**, так как он исключает сетевые блокировки и не требует ввода персональных данных.

### 1.2. Подключение живого почтового ящика (Google Gmail)

Для работы с реальным ящиком Google требуется 16-значный **«Пароль приложения»** (обычный пароль от аккаунта Google отклоняется в целях безопасности).

1. Перейдите в управление аккаунтом Google: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords).
2. В поле «Название приложения» укажите: `1C Assistant` и нажмите кнопку **«Создать»**.
3. Скопируйте сгенерированный 16-значный пароль (например: `xrgg ypzn ysfg jbke`).
4. Откройте файл `Middleware/.env` и укажите реквизиты:
   ```ini
   # ─── КОРПОРАТИВНАЯ ПОЧТА (GMAIL) ─────────────────────────
   DIRECTOR_EMAIL=director@yourcompany.ru    # Куда доставлять дайджесты и алерты
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465                             # Защищенный протокол SSL
   SMTP_USER=your_bot_email@gmail.com        # Логин робота-отправителя
   SMTP_PASSWORD=xrggypznysfgjbke            # 16-значный пароль приложения (без пробелов)
   SMTP_FROM=your_bot_email@gmail.com

   IMAP_HOST=imap.gmail.com
   IMAP_PORT=993                             # SSL-порт для входящей почты
   IMAP_USER=your_bot_email@gmail.com
   IMAP_PASSWORD=xrggypznysfgjbke
   ```
5. Перезапустите Middleware: `python main.py`.

### 1.3. Подключение почтового ящика Яндекс (Yandex Mail)

1. Перейдите в настройки безопасности Яндекс ID: [id.yandex.ru/security](https://id.yandex.ru/security).
2. В блоке «Пароли приложений» выберите тип **«Почта»** и создайте пароль.
3. В файле `Middleware/.env` задайте:
   ```ini
   SMTP_HOST=smtp.yandex.ru
   SMTP_PORT=465
   SMTP_USER=your_login@yandex.ru
   SMTP_PASSWORD=ваш_пароль_приложения_яндекс
   SMTP_FROM=your_login@yandex.ru

   IMAP_HOST=imap.yandex.ru
   IMAP_PORT=993
   IMAP_USER=your_login@yandex.ru
   IMAP_PASSWORD=ваш_пароль_приложения_яндекс
   ```

### 1.4. Подключение почтового ящика Mail.ru

1. Перейдите в настройки безопасности Mail.ru: [account.mail.ru/user/security](https://account.mail.ru/user/security) $\rightarrow$ «Пароли для внешних приложений».
2. Создайте новый пароль для приложения «1C Assistant».
3. В файле `Middleware/.env` задайте:
   ```ini
   SMTP_HOST=smtp.mail.ru
   SMTP_PORT=465
   SMTP_USER=your_login@mail.ru
   SMTP_PASSWORD=ваш_пароль_приложения_mailru
   SMTP_FROM=your_login@mail.ru

   IMAP_HOST=imap.mail.ru
   IMAP_PORT=993
   IMAP_USER=your_login@mail.ru
   IMAP_PASSWORD=ваш_пароль_приложения_mailru
   ```

## 2. Подключение Telegram-бота

1. Откройте `@BotFather` в Telegram и выполните команду `/newbot`.
2. Задайте имя и username бота (например: `MyUNF_AI_Bot`).
3. Скопируйте выданный HTTP API токен.
4. В файле `Middleware/.env` укажите:
   ```ini
   TELEGRAM_BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
5. Бот работает в режиме **Long Polling**: для его работы **не требуется белый статический IP-адрес или домен**, он принимает команды и голосовые сообщения сразу после запуска `python main.py`.

---

## 3. Подключение бота ВКонтакте (Сообщество VK)

1. Создайте или откройте существующее сообщество ВКонтакте.
2. Перейдите в **«Управление»** $\rightarrow$ **«Сообщения»** $\rightarrow$ включите сообщения сообщества.
3. Перейдите в **«Управление»** $\rightarrow$ **«Работа с API»**:
   * Вкладка **«Ключи доступа»** $\rightarrow$ «Создать ключ» $\rightarrow$ отметьте права: *«Доступ к сообщениям сообщества»*.
   * Скопируйте токен (начинается на `vk1.a...`).
   * Вкладка **«Long Poll API»** $\rightarrow$ включите Long Poll, версия API: `5.131`, во вкладке «Типы событий» отметьте галочкой *«Входящие сообщения»*.
4. Скопируйте цифровой ID сообщества из адресной строки (например, `241251337`).
5. В файле `Middleware/.env` укажите:
   ```ini
   VK_GROUP_ID=241251337
   VK_GROUP_TOKEN=vk1.a.XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX...
   ```

## 4. Сценарии демонстрации для членов жюри

| № | Канал | Действие пользователя | Реакция системы 1С:УНФ |
|---|---|---|---|
| **1** | **Email** | Клиент присылает письмо на почту с текстом заявки: *«Прошу выставить счет на кабель ВВГнг 100м»* | Робот парсит номенклатуру, создает задачу в Канбане 1С (`🔴 Срочно`) и автоматически отправляет клиенту красивое подтверждение регистрации. |
| **2** | **Email** | Руководитель нажимает «Дайджест» или срабатывает утренний триггер | На email руководителя уходит сверстанный HTML-дайджест с 4 карточками KPI и ключевыми сигналами дня. |
| **3** | **Telegram** | Руководитель нажимает кнопку микрофона и наговаривает голосом: *«Какова вероятность кассового разрыва на этой неделе?»* | Ассистент выполняет Whisper STT, рассчитывает платежный календарь и присылает форматированную сводку с кнопками быстрых действий. |
| **4** | **VKontakte** | Менеджер нажимает в меню кнопку `📋 Канбан задач` | Бот мгновенно генерирует актуальный статус очереди задач из регистров 1С с исполнителями и дедлайнами. |
