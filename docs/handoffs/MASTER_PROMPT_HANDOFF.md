### 4. ВАЖНЫЕ ТЕХНИЧЕСКИЕ ТОНКОСТИ, ВЫЯВЛЕННЫЕ ПРИ ДЕБАГЕ:
- **Договоры контрагентов в УНФ 3.0:** У объекта `Справочник.Контрагенты` отсутствует реквизит `ОсновнойДоговорКонтрагента`. Поиск договора выполняется запросом: `ВЫБРАТЬ Ссылка ИЗ Справочник.ДоговорыКонтрагентов ГДЕ Владелец = &Владелец И НЕ ПометкаУдаления`.
- **Реквизиты документов УНФ:** В «Заказе покупателя» контрагент хранится в реквизите `Контрагент` (а не `Покупатель`). Документы требуют обязательного заполнения реквизитов `СостояниеЗаказа`, `ВалютаДокумента`, `ПоложениеСклада = Перечисления.ПоложениеРеквизитаНаФорме.ВШапке`.
- **Открытие карточек объектов 1С:** Для открытия форм контрагентов, номенклатуры и заказов используется метод `ПоказатьЗначение(, Ссылка)`, исключающий ошибки имен форм.
- **Параметры ссылок в HTML:** Разбор URL-параметров выполняется функцией `ШПолучитьПараметр` с безопасной работой через `Структура`.
