## АРХИТЕКТУРНЫЙ ИНТЕРФЕЙС ГРАФИЧЕСКОГО ДВИЖКА (presentation_engine.py)

В твоем распоряжении уже имеется модуль `presentation_engine.py`. ТЕБЕ ЗАПРЕЩЕНО рисовать примитивные стандартные серые фигуры напрямую! Ты обязан использовать методы класса `PresentationEngine`:

```python
from presentation_engine import (
    PresentationEngine,
    COLOR_BRAND_1C,        # #FFB300 - Золото 1С
    COLOR_BRAND_YELLOW,    # #FFE600 - Яркий акцент
    COLOR_TECH_CYAN,       # #06B6D4 - RAG, шины, векторы
    COLOR_TECH_INDIGO,     # #6366F1 - Архитектурные связи
    COLOR_SUCCESS_GREEN,   # #10B981 - 100% тестов, белый список
    COLOR_DANGER_RED,      # #EF4444 - 115-ФЗ, отсечка DoS 429
    COLOR_CARD_BORDER,     # #334155 - Тонкий контур карточек
    COLOR_CARD_BG,         # #1E293B - Подложка карточек
    COLOR_TEXT_PRIMARY,    # #FFFFFF - Белый заголовков
    COLOR_TEXT_MUTED,      # #94A3B8 - Серебристый текст
    Inches, Pt
)

engine = PresentationEngine()
```

### Основные методы движка:

1. `create_slide(title, subtitle=None, category_badge=None, badge_color=COLOR_TECH_CYAN, slide_num=None)`
   - Создает слайд 16:9 (`13.333` x `7.5` дюймов), темный фон `#0B0F19`, категорийный бейдж в верхнем углу, заголовок (22 pt, Bold, `#FFFFFF`), подзаголовок (12 pt, `#94A3B8`), разделительную линию и номер слайда (`01 / 18`).

2. `add_card(slide, left, top, width, height, title=None, body=None, bullets=None, badge_text=None, badge_color=COLOR_BRAND_1C, border_color=COLOR_CARD_BORDER, fill_color=COLOR_CARD_BG, title_color=COLOR_TEXT_PRIMARY, body_font_size=Pt(11.5))`
   - Создает карточку со скруглением 4%, тонкой рамкой 1.0 pt, внутренними отступами (0.24 дюйма), автоматическим переносом строк, заголовком, описанием и маркированным списком.

3. `add_metric_card(slide, left, top, width, height, value, label, subtext=None, accent_color=COLOR_BRAND_1C, badge_text=None)`
   - Создает карточку KPI с огромным моноширинным числом (32 pt JetBrains Mono Bold), заголовком метрики и поясняющим текстом.

4. `add_badge(slide, left, top, text, bg_color=COLOR_CARD_BG, text_color=COLOR_BRAND_1C, font_size=Pt(10), height=Inches(0.32))`
   - Создает компактный бейдж-чип в форме капсулы со скруглением 50%.

5. `add_pipeline(slide, left, top, width, height, steps)`
   - Создает горизонтальный архитектурный пайплайн. `steps` — список словарей: `[{"title": "1. Сбор", "desc": "...", "color": COLOR_TECH_CYAN}, ...]`.

6. `add_table(slide, left, top, width, height, headers, rows, col_widths=None)`
   - Отрисовывает контрастную корпоративную таблицу с темно-синими строками и золотыми заголовками.

7. `add_speaker_notes(slide, notes_text)`
   - Помещает сценарий доклада спикера в нативные заметки PowerPoint.

8. `save(filepath)`
   - Сохраняет презентацию в нативный файл `.pptx`.

## ЖЕСТКИЕ ПРАВИЛА ВЕРСТКИ
1. **Кавычки-елочки:** В русском тексте использовать строго «...» вместо прямых "...".
2. **Точные числа:** Строго `945.6 RPS`, `1.06 мс`, `p95 1.39 мс`, `431 мс`, `150 ACID-транзакций`, `62 автотеста (100 % Pass Rate)`, `115-ФЗ`, `ст. 395 ГК РФ`, `ГОСТ Р 56042-2014`.
3. **Без плейсхолдеров:** Запрещены фразы «Текст слайда», «Lorem ipsum» или пустые контейнеры.
4. **Спикер-ноутс:** К каждому слайду обязательно добавлять `add_speaker_notes()` с текстом доклада на 20–35 секунд.
