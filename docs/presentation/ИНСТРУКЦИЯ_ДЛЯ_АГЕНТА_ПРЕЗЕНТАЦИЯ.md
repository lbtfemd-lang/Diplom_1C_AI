Проект: **«Интеллектуальный ассистент и омниканальный интеграционный слой для типовой конфигурации „1С:Управление нашей фирмой 3.0“»**.

## 3. БЫСТРЫЙ СТАРТ

### Шаг 1. Установка окружения (если требуется сборка локально)
```bash
pip install -r requirements.txt
```

### Шаг 2. Проверка текущей презентации
Запусти валидатор качества, чтобы убедиться в отсутствии ошибок:
```bash
python .agents/skills/presentation-expert/scripts/validate_deck.py presentation/Интеллектуальный_ассистент_для_1С_УНФ_КОНКУРС.pptx
```

### Шаг 3. Пересборка или модификация слайдов
Если вносятся изменения в дизайн, цвета или тексты:
- Отредактируй скрипт `.agents/skills/presentation-expert/scripts/build_pptx_deck.py`.
- Запусти сборку:
```bash
python .agents/skills/presentation-expert/scripts/build_pptx_deck.py presentation/Интеллектуальный_ассистент_для_1С_УНФ_КОНКУРС.pptx
```

## 4. КЛЮЧЕВЫЕ ИНЖЕНЕРНЫЕ ПРАВИЛА (СТРОГО СОБЛЮДАТЬ!)

1. **Формат и стиль:**
   - Строго **16:9** widescreen ($13.333'' \times 7.5''$).
   - Стиль **Modern Dark Enterprise**: фон `#0F172A`, карточки `#1E293B` с тонкими рамками `#334155`, акценты 1С золотой `#FFB300` и циан `#06B6D4`.
   - Контрастность текста $\ge 4.5:1$ (белый или светлый циан на темном фоне).
2. **Точные факты и цифры (Zero-Fiction):**
   - Ровно **62 теста** pytest (100 % pass rate).
   - Нагрузочный тест Locust: **945.6 RPS** при задержке **1.06 мс**, Burst RAG 20 сессий со средней задержкой **2.24 с** (медиана **431 мс**).
   - Транзакционная надежность: **150 ACID-операций** в режиме SQLite WAL без взаимных блокировок.
   - Шесть прикладных сервисов: **115-ФЗ**, **ст. 395 ГК РФ**, **ROP/EOQ Уилсона**, **защита маржинальности**, **OCR первичных документов**, **QR-коды СБП по ГОСТ Р 56042-2014**.
   - Никаких вымышленных контрактов или поддельных актов внедрения.
3. **Объем текста:**
   - Не более 30–45 слов на слайд. Никаких «стен текста»!
   - Каждый слайд обязан содержать заметки докладчика (Speaker Notes).
   - Использовать русские кавычки-елочки (« »).
