### СЛАЙД 7. БЕЗОПАСНОСТЬ И КОНТРОЛЬ: МЕХАНИЗМ ACTION WHITELIST

  - Шаг 1. *Синтаксический разбор:* Нейросеть генерирует строго типизированный JSON со схемой `{"action": string, "data": dict}`.

  - Шаг 4. *Изоляция транзакций:* Никакого оператора `Выполнить()` или прямого выполнения BSL-кода из текста! Открытие форм выполняется только на клиенте через `БезопасноОткрытьФорму()`.
- **Ключевой бейдж:** `0 % вероятность SQL-инъекций или несанкционированного изменения проводок`.
- **Заметки для спикера (25 сек):** «Мы полностью исключили возможность выполнения сгенерированного кода в транзакционном пространстве 1С. Ассистент возвращает лишь декларативные команды, которые клиентский модуль 1С сверяет с жестким белым списком и правами текущей роли».

### СЛАЙД 8. ДЕТЕРМИНИРОВАННЫЙ РОУТИНГ И ОФФЛАЙН-РЕЖИМ
