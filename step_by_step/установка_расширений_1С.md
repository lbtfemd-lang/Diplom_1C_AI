## 1. Предварительные требования

### Что должно быть установлено

| Компонент | Версия | Проверка |
|-----------|--------|----------|
| 1С:Предприятие | 8.5.1.1150+ | `C:\Program Files\1cv8\8.5.1.1150\bin\1cv8.exe` |
| Шаблон «Управление нашей фирмой» | Любая | Меню стартера → Создать → ищем УНФ в списке |
| Middleware (Python) | Запущен | http://127.0.0.1:8000/ → `{"status":"ok"}` |

> [!IMPORTANT]
> **Middleware должен быть запущен ДО начала работы с расширениями.**
> Подробная инструкция по запуску Middleware: [запуск_middleware.md](запуск_middleware.md)

### Файлы расширений (из папки `1c_extensions/`)

| Файл | Расширение | Что содержит |
|------|------------|--------------|
| `1C_Full_Code_v6.bsl` | ИнтеллектуальныйАссистент | HTML-чат + 19 команд + диспетчер |
| `1C_Kanban_Extension.bsl` | КанбанДоска | HTML-канбан доска (десктоп) |
| `1C_Kanban_Mobile.bsl` | КанбанДоска | Канбан мобильная форма (опционально) |
| `1C_Shared_HTTP.bsl` | — | Справочный шаблон (уже встроен в оба .bsl) |

> [!NOTE]
> Файл `1C_Shared_HTTP.bsl` — **справочный**. Код из него уже включён в оба расширения
> (блок `SHARED_HTTP_START..SHARED_HTTP_END` в конце каждого .bsl-файла).
> Отдельно его вставлять не нужно.

## 2. Создание информационной базы

> Если у вас уже есть база УНФ — **пропустите** этот раздел и переходите к Шагу 3.

### 2.1. Запустить стартер 1С

- **Пуск** → **1С:Предприятие 8** (или двойной клик по `C:\Program Files\1cv8\8.5.1.1150\bin\1cv8.exe`)

### 2.2. Создать базу

1. В окне стартера нажмите **«Добавить»** (или **«Создать»** если окно списка баз пустое)
2. Выберите **«Создание информационной базы»** → **Далее**
3. Выберите **«Создание информационной базы из шаблона»**
4. В дереве шаблонов найдите:
   - **1С:Управление нашей фирмой** (`smallbusiness`)
   - или **1С:Управление нашей фирмой, базовая** (`smallbusinessbase`)
5. Нажмите **Далее**

### 2.3. Настроить параметры базы

| Параметр | Значение |
|----------|----------|
| **Название** | `УНФ Диплом` (или любое) |
| **Тип расположения** | На данном компьютере |
| **Каталог базы** | `C:\Users\<Ваш_пользователь>\Documents\1C\UNF_Diplom` |
| **Режим** | Файловый (по умолчанию) |

6. Нажмите **Готово** → дождитесь создания базы (1–3 минуты)

### 2.4. Первичная настройка УНФ

1. После создания 1С предложит открыть базу → нажмите **«1С:Предприятие»**
2. Пройдите мастер первоначальной настройки:
   - Название организации — любое (например: `ООО Тест`)
   - Остальные параметры — можно оставить по умолчанию
3. После завершения мастера → **закройте** 1С

## 3. Расширение 1: «ИнтеллектуальныйАссистент»

### 3.1. Открыть базу в Конфигураторе

1. Запустите стартер 1С
2. Выберите вашу базу (`УНФ Диплом`)
3. В выпадающем списке справа от кнопки **«1С:Предприятие»** выберите **«Конфигуратор»**
4. Нажмите **«1С:Предприятие»** (кнопка теперь запустит Конфигуратор)

### 3.2. Создать расширение

1. Меню → **Конфигурация** → **Расширения конфигурации**
2. В открывшемся окне нажмите кнопку **«Добавить»** (иконка ➕)
3. В появившемся диалоге заполните:

| Поле | Значение |
|------|----------|
| **Имя** | `ИнтеллектуальныйАссистент` |
| **Синоним** | `Интеллектуальный ассистент` |
| **Назначение** | `Дополнение` |
| **Префикс** | `ИА_` |

4. **‼️ КРИТИЧЕСКИ ВАЖНО — снять две галочки:**

   - ❌ **Безопасный режим** — СНЯТЬ
   - ❌ **Защита от опасных действий** — СНЯТЬ

> [!CAUTION]
> Если не снять эти галочки, расширение **не сможет выполнять HTTP-запросы** к middleware.
> Ошибка будет: `«Доступ к операции запрещен»` или молчаливый отказ.

5. Нажмите **ОК**

### 3.3. Создать обработку «ЧатСАссистентом»

1. В левой части экрана откроется дерево расширения
2. Найдите узел **«Обработки»**
3. Правой кнопкой мыши → **«Добавить»**
4. В свойствах обработки (справа):

| Поле | Значение |
|------|----------|
| **Имя** | `ЧатСАссистентом` |
| **Синоним** | `Чат с ассистентом` |

### 3.4. Создать основную форму

1. В свойствах обработки перейдите на вкладку **«Формы»**
2. Нажмите **«Добавить»** (➕)
3. Тип формы: **Форма обработки** → **ОК**
4. Поставьте галочку **«Основная форма»** (если не стоит)
5. Откройте форму двойным кликом

### 3.5. Добавить реквизиты формы

> В открывшемся редакторе формы найдите панель **«Реквизиты»** (обычно справа вверху).
> Нажмите кнопку **«Добавить реквизит»** (иконка ➕ над деревом реквизитов) для каждого:

#### Обычные реквизиты (8 штук):

| № | Имя | Тип | Длина | Примечание |
|---|-----|-----|-------|------------|
| 1 | `ЧатHTML` | Строка | 0 (неограниченная) | Отображение чата |
| 2 | `ТекстСообщения` | Строка | 0 (неограниченная) | Поле ввода пользователя |
| 3 | `ФлагЗагрузки` | Булево | — | Индикатор загрузки |
| 4 | `АдресMiddleware` | Строка | 100 | Адрес сервера (по умолч. `127.0.0.1`) |
| 5 | `ЛогинMiddleware` | Строка | 100 | Логин (по умолч. `1c_service`) |
| 6 | `ПарольMiddleware` | Строка | 100 | Пароль (по умолч. `1c_service_2024`) |
| 7 | `ИспользоватьHTTPS` | Булево | — | Флаг HTTPS (по умолч. `Ложь`) |
| 8 | `MiddlewareТокен` | Строка | 500 | JWT-токен (заполняется автоматически) |

> [!WARNING]
> **Имена реквизитов должны совпадать СИМВОЛ В СИМВОЛ!**
> Код обращается к ним по имени. Ошибка в одной букве → ошибка компиляции.

#### Таблица значений (1 штука):

1. Нажмите **«Добавить реквизит»** (➕)
2. **Имя**: `ЧатИстория`
3. **Тип**: Таблица значений (или ТаблицаЗначений)
4. Раскройте узел `ЧатИстория` и добавьте **4 колонки** (правой кнопкой → «Добавить» для каждой):

| Колонка | Тип | Длина |
|---------|-----|-------|
| `Автор` | Строка | 100 |
| `Текст` | Строка | 0 (неограниченная) |
| `Время` | Строка | 10 |
| `ТипСообщения` | Строка | 20 |

### 3.6. Разместить элементы на форме

> Перетаскивайте реквизиты из панели «Реквизиты» (справа) на форму (слева).

**Шаг 1. HTML-поле чата (основной элемент):**
1. Перетащите `ЧатHTML` на форму
2. В свойствах элемента (внизу): **Вид** → **Поле HTML документа**
3. Растяните по всей форме (это будет основная область чата)

**Шаг 2. Поле ввода сообщений:**
1. Перетащите `ТекстСообщения` на форму → разместите **ВНИЗУ** под HTML-полем
2. Оставьте тип по умолчанию (поле ввода)

**Шаг 3. Скрытые элементы:**
1. Перетащите `ФлагЗагрузки` на форму → правой кнопкой → **«Видимость»** → снять
2. Перетащите `ЧатИстория` на форму (как таблицу) → правой кнопкой → **«Видимость»** → снять
3. Перетащите `АдресMiddleware` на форму → правой кнопкой → **«Видимость»** → снять

> [!TIP]
> Скрытые элементы нужны коду, но не должны быть видны пользователю.
> Альтернатива: можно не перетаскивать, а убедиться что код находит реквизиты.
> Но таблицу `ЧатИстория` лучше добавить на форму как элемент и скрыть.

### 3.7. Добавить быстрые кнопки (5 штук)

В панели **«Элементы формы»** (слева):
1. Правой кнопкой → **«Добавить»** → **«Кнопка»**
2. Повторите для каждой из 5 кнопок:

| Имя кнопки (свойство «Имя») | Заголовок (текст на кнопке) | Отображение |
|------------------------------|----------------------------|-------------|
| `ЗаказыНажатие` | `Заказы` | Только текст |
| `КанбанНажатие` | `📌 Канбан` | Только текст |
| `СегодняНажатие` | `📊 Сегодня` | Только текст |
| `ДолжникиНажатие` | `Должники` | Только текст |
| `КлиентыНажатие` | `Клиенты` | Только текст |

3. Разместите кнопки **вверху формы** в один ряд (над HTML-полем чата)
4. Для каждой кнопки в свойствах: **Отображение** = **Только текст**

> [!NOTE]
> Имя кнопки = имя обработчика клика в коде. Например, кнопка `ЗаказыНажатие`
> вызовет процедуру `ЗаказыНажатие(Элемент)` в модуле формы.

### 3.8. Добавить команду «Отправить»

1. В редакторе формы перейдите на вкладку **«Команды»** (внизу)
2. Нажмите **«Добавить»** (➕)
3. **Имя команды**: `ОтправитьСообщение`
4. Перетащите команду на форму — рядом с полем `ТекстСообщения` (внизу)
5. Текст кнопки: `Отправить`

### 3.9. Вставить код модуля формы

> [!CAUTION]
> Используйте **Notepad++**, **VS Code** или **Sublime Text** для открытия .bsl файлов.
> **НЕ** используйте стандартный Блокнот Windows — он может сломать кодировку UTF-8!

1. Перейдите на вкладку **«Модуль»** в редакторе формы
2. Выделите весь текст: **Ctrl+A**
3. Удалите: **Delete**
4. Откройте файл `1c_extensions\1C_Full_Code_v6.bsl` в Notepad++ или VS Code
5. Выделите **ВСЁ содержимое** файла: **Ctrl+A**
6. Скопируйте: **Ctrl+C**
7. Вернитесь в Конфигуратор → вкладка «Модуль»
8. Вставьте: **Ctrl+V**
9. Сохраните: **Ctrl+S**

### 3.10. Проверить синтаксис

1. Нажмите **F8** (или Меню → Отладка → Синтаксический контроль модуля)
2. **Ожидаемый результат**: `Синтаксических ошибок не обнаружено`

**Если ошибки есть — типичные причины:**

| Ошибка | Причина | Как исправить |
|--------|---------|---------------|
| `Переменная "ЧатИстория" не определена` | Реквизит не создан или имя написано с ошибкой | Проверить имя реквизита (п. 3.5) |
| `Переменная "ТекстСообщения" не определена` | Аналогично | Проверить имя точно: `ТекстСообщения` |
| `Переменная "MiddlewareТокен" не определена` | Реквизит не создан | Создать реквизит `MiddlewareТокен` (Строка, 500) |
| `Процедура или функция "ЭтоМобильныйКлиент" не определена` | Код скопирован не полностью | Скопировать заново, до самого конца файла |
| `Ожидается символ КонецЕсли` | Код обрезан | Убедиться что скопировано ВСЁ |

| **Назначение** | `Дополнение` |

## 5. Первый запуск и проверка

### 5.1. Убедиться что Middleware запущен

Откройте браузер → http://127.0.0.1:8000/ → должно вернуть:
```json
{"status":"ok","service":"1C AI Assistant Middleware"}
```

Если не работает — запустите:
```
Двойной клик на start.bat в папке проекта
```
или:
```powershell
cd D:\Share\Projects\diplom\Middleware
.venv\Scripts\python main.py
```

### 5.2. Запустить 1С:Предприятие

1. В Конфигураторе нажмите **F5** (или Меню → Отладка → Начать отладку)
2. 1С запустится в режиме Предприятия

### 5.3. Открыть чат-ассистент

1. В 1С:Предприятие → Меню → **Все функции** (или **Функции для технического специалиста**)

> [!TIP]
> Если пункта «Все функции» нет — включите его:
> **Главное меню** → **Сервис** → **Параметры** → ✅ **Отображать команду «Все функции»**

2. В списке найдите: **Обработки** → **ЧатСАссистентом**
3. Откройте двойным кликом

### 5.4. Первичная авторизация

При первом открытии чат автоматически авторизуется с сервисным аккаунтом:
- **Логин**: `1c_service`
- **Пароль**: `1c_service_2024`

Это происходит прозрачно для пользователя.

> Для ручной авторизации через чат введите: `admin` / `admin`

### 5.5. Обновить метаданные

## 6. Решение типичных проблем

### Ошибки компиляции (F8)

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Переменная "ЧатИстория" не определена` | Реквизит не создан или неправильное имя | Проверить что реквизит `ЧатИстория` существует (тип: ТаблицаЗначений) |
| `Переменная "MiddlewareТокен" не определена` | Реквизит отсутствует | Создать реквизит `MiddlewareТокен` (Строка, 500) |
| `Ожидается символ КонецЕсли` | Код скопирован не полностью | Скопировать файл заново, убедиться что скопировано до конца |
| `Неизвестная функция "ШПолучитьТокенАвторизации"` | Блок Shared HTTP не скопирован | Убедиться что .bsl файл скопирован полностью (включая блок в конце) |

### Ошибки при запуске

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Ошибка связи с сервером» | Middleware не запущен | Запустить `start.bat` или `python main.py` |
| «Доступ к операции запрещен» | Безопасный режим включён | Снять галочки (п. 3.2 шаг 4) |
| Канбан не открывается | Неправильное имя обработки | Проверить: имя = `КанбанДоска`, регистр важен! |
| HTML-поле не рендерит (показывает текст) | Неправильный тип элемента | В свойствах: **Вид** = **Поле HTML документа** |
| «Не авторизован» в чате | Токен не получен | Перезапустить форму, проверить что middleware на 127.0.0.1:8000 |
| Ошибка `[Errno 10048]` в middleware | Порт 8000 занят | `Get-Process -Name python | Stop-Process` и перезапустить |

### Ошибки Middleware

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: No module named 'pydantic_core._pydantic_core'` | Удалить `.venv`, пересоздать: `python -m venv .venv` |
| `pip install` падает с ошибкой кэша | `pip install --no-cache-dir -r requirements.txt` |
| sentence-transformers не устанавливается | Остальные функции работают, но текущий RAG без embeddings не возвращает кандидатов |

## 7. Справочник файлов проекта

### Файлы расширений

| Файл | Строк кода | Описание |
|------|-----------|----------|
| `1C_Full_Code_v6.bsl` | ~1127 | Полный код чат-ассистента: HTML-чат, 19 команд, RAG, диспетчер действий |
| `1C_Kanban_Extension.bsl` | ~524 | Канбан-доска: HTML-рендер, CRUD задач, фильтры |
| `1C_Kanban_Mobile.bsl` | ~500 | Мобильная форма канбана: нативная таблица значений |
| `1C_Shared_HTTP.bsl` | ~166 | Шаблон общих HTTP-функций (встроен в оба расширения) |

### Структура обоих расширений

```
Расширение «ИнтеллектуальныйАссистент» (ИА_)
└── Обработки
    └── ЧатСАссистентом
        └── Формы
            └── Форма (основная)
                ├── Реквизиты: ЧатHTML, ТекстСообщения, ФлагЗагрузки,
                │              АдресMiddleware, ЛогинMiddleware,
                │              ПарольMiddleware, ИспользоватьHTTPS,
                │              MiddlewareТокен
                ├── Таблица: ЧатИстория (Автор, Текст, Время, ТипСообщения)
                ├── Кнопки: Заказы, 📌 Канбан, 📊 Сегодня, Должники, Клиенты
                ├── Команда: ОтправитьСообщение
                └── Модуль: 1C_Full_Code_v6.bsl

Расширение «КанбанДоска» (КД_)
└── Обработки
    └── КанбанДоска
        └── Формы
            ├── Форма (основная, десктоп)
            │   ├── Реквизиты: КанбанHTML, АдресMiddleware,
            │   │              ЛогинMiddleware, ПарольMiddleware,
            │   │              ИспользоватьHTTPS, MiddlewareТокен
            │   ├── Кнопки: Обновить, + Задача
            │   └── Модуль: 1C_Kanban_Extension.bsl
            └── МобильнаяФорма (опционально)
                ├── Реквизиты: ЗадачиТаблица, АдресMiddleware
                ├── Кнопки: Обновить, + Задача, Переместить, Удалить
                └── Модуль: 1C_Kanban_Mobile.bsl
```
