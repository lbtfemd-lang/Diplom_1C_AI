# ВВЕДЕНИЕ

Учетные системы на платформе «1С:Предприятие» служат ядром операционной деятельности современных компаний. Они объединяют продажи, закупки, складской учет, расчеты с контрагентами и финансовый анализ. Однако эффективность такой системы напрямую зависит от работы сотрудников: насколько легко они ориентируются в сложном интерфейсе, как быстро находят документы и понимают ли логику проведения операций. 

Логичным решением становится внедрение интеллектуальных ассистентов, способных понимать естественную речь, давать подсказки по методологии учета и запускать нужные действия в программе. Использование больших языковых моделей (LLM) для этих целей требует решения специфических задач: обеспечения безопасности при запуске транзакций и адаптации модели под конкретную структуру базы данных. В проекте реализован комбинированный подход: семантический поиск по метаданным (RAG) для контекстуализации запросов, авторизация по токенам JWT для разграничения доступа и безопасный запуск команд на стороне 1С по белому списку (whitelist).

Разработка прототипа системы выполнена с ориентацией на бизнес-процессы ООО «ЛюксонДекор» — торговой компании, специализирующейся на оптовых и розничных продажах отделочных материалов. Использование ассистента позволяет оптимизировать процессы навигации в базе 1С:УНФ, ускорить поиск документов, упростить подготовку заказов и обеспечить оперативный контроль задач с помощью встроенной канбан-доски.

Объект исследования — процессы взаимодействия пользователей с прикладными объектами 1С:УНФ при поиске, создании и анализе документов и справочников.

Предмет исследования — методы проектирования и разработки встроенного интеллектуального помощника в среде «1С:Предприятие» с использованием веб-технологий, семантического поиска по метаданным и разграничения прав доступа.

Цель проекта — создание и экспериментальная апробация программного расширения «Интеллектуальный ассистент» для конфигурации «1С:Управление нашей фирмой 3.0», позволяющего вести диалог с системой на естественном языке, находить и открывать формы, подготавливать документы, запрашивать аналитические показатели, работать с канбан-доской и проходить ролевую авторизацию.

Для достижения поставленной цели решены следующие задачи:
- выполнен анализ бизнес-процессов ООО «ЛюксонДекор» и выявлены ключевые затруднения пользователей при работе с интерфейсом 1С:УНФ;
- сформулированы функциональные и нефункциональные требования к архитектуре и компонентам интеллектуального ассистента;
- проведен обзор существующих отечественных аналогов и обоснован выбор клиент-серверной архитектуры на основе расширения 1С и сервисного middleware;
- спроектированы алгоритмы взаимодействия расширения 1С, Python-middleware и больших языковых моделей;
- разработана реляционная структура базы данных для хранения задач канбан-доски и параметров учетных записей;
- реализовано расширение для платформы «1С:Предприятие 8.3», включающее гибридное окно чата и диспетчер выполнения команд из белого списка;
- разработан асинхронный сервер на базе веб-фреймворка FastAPI, интегрированный с интерфейсами языковых моделей и реализующий механизм токенной JWT-авторизации;
- реализован модуль семантического поиска (RAG) по метаданным 1С на основе векторных представлений и резервных эвристических алгоритмов;
- создан интерактивный веб-компонент канбан-доски с ролевой фильтрацией задач и REST-взаимодействием с информационной базой;
- проведено комплексное автоматизированное тестирование с помощью фреймворка pytest и ручная верификация пользовательских сценариев;
- выполнена расчетная оценка потенциального технико-экономического эффекта от использования разработанного ассистента;
- подготовлены рекомендации по установке, проверке и эксплуатации разработанного решения.

Методы исследования — системный анализ прикладных процессов, объектно-ориентированное проектирование программных комплексов, методы информационной безопасности и токенной аутентификации, математические методы векторного семантического поиска, функциональное и нагрузочное тестирование.

Практическая ценность работы заключается в создании учебного программного прототипа расширения для конфигурации «1С:Управление нашей фирмой 3.0». Прототип демонстрирует, как единое окно ассистента может поддерживать поиск объектов, подготовку типовых действий и работу с задачами; возможность тиражирования и фактический экономический эффект требуют отдельной проверки в целевой организации.

Научная новизна работы состоит в создании гибридной интерфейсной архитектуры, объединяющей динамический HTML-рендеринг веб-компонентов с нативными формами платформы 1С (включая режим мобильного клиента), а также в разработке отказоустойчивого протокола валидации структурированных команд с жесткой проверкой по белому списку на стороне 1С для предотвращения некорректного поведения нейросетевых моделей.

По своей структуре выпускная квалификационная работа состоит из введения, трех глав, заключения, списка использованных источников и приложений.
