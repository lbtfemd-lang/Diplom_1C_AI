Рисунок 2.1 — Архитектура решения: компоненты и взаимосвязи

Слой 1 (y=100, h=200): Большой прямоугольник с оранжевой обводкой, заливка #FFF3E0
- Заголовок слоя: КЛИЕНТСКАЯ ЧАСТЬ (1С:УНФ) — оранжевый жирный
- Содержимое (5 строк, с буллитами):
  • Форма чата: ЧатИстория + КанбанHTML
  • Условное оформление: user=#E67E22, bot=#363636
  • Быстрые кнопки: Заказы, Канбан, Должники
  • Диспетчер команд: ВыполнитьКомандуАссистента
  • Сбор метаданных: СобратьМетаданныеНаСервере

Слой 2 (y=350, h=380): Большой прямоугольник с синей обводкой, заливка #E3F2FD
- Заголовок слоя: СЕРВЕРНАЯ ЧАСТЬ (Middleware / Python / FastAPI) — синий жирный
- 5 внутренних блоков (каждый 340×260, с зазором 30px между ними):
  1. auth_service (оранжевый): JWT + bcrypt, Роли: admin / manager / employee
  2. kanban_service (зелёный): CRUD задач, Фильтрация, CSV-экспорт, Просроченные
  3. llm_service (фиолетовый): System prompt, RAG-контекст, Разбор JSON, Post-processing
  4. metadata_service (фиолетовый): Эмбеддинги (.npy), Cosine similarity, Top-k
  5. API-слой (синий): /chat, /auth/*, /kanban/*, /update_metadata, /health

Слой 3 (y=780, h=100): Прямоугольник с зелёной обводкой, заливка #E8F5E9
- Заголовок: LLM-ПРОВАЙДЕР (Fireworks AI / GLM-5.1 / OpenAI-совместимый API)

Хранилища (правее слоя 3): два малых блока
- metadata_index_lite.json (серый)
- kanban.db (SQLite) (серый)

Стрелки между слоями:
- Слой1 → Слой2: вниз, подпись HTTP 127.0.0.1:8000
- Слой2 → Слой1: вверх пунктиром
- Слой2 → Слой3: вниз
- Слой3 → Слой2: вверх пунктиром
