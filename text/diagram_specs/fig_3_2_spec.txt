Рисунок 3.2 — Схема RAG: от запроса пользователя к структурированному ответу

7 блоков в ряд (y=130, каждый 240×180, зазор 50px):

| # | Блок                 | Цвет         | Текст внутри (крупно) | Подпись ПОД блоком (мельче)          |
|---|----------------------|--------------|------------------------|--------------------------------------|
| 1 | Запрос пользователя  | оранжевый    | Запрос / пользователя  | Естественный язык                    |
| 2 | Векторизация         | фиолетовый   | Векторизация / запроса | SentenceTransformer / 384d           |
| 3 | Cosine similarity    | синий        | Cosine / similarity    | 1423 объекта / .klargest(7)          |
| 4 | Top-7                | фиолетовый   | Top-7 / кандидатов     | name + synonym / + fields[type]       |
| 5 | System prompt        | синий        | System / prompt        | RAG-контекст / + few-shot            |
| 6 | LLM                  | зелёный      | LLM / GLM-5.1          | Fireworks AI API                     |
| 7 | JSON ответ           | оранжевый    | JSON / ответ           | {text, action, data}                 |

Между каждыми соседними блоками — стрелка → (толстая, с наконечником).
