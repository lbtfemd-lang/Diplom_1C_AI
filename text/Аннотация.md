# АННОТАЦИЯ / ABSTRACT

## АННОТАЦИЯ
на выпускную квалификационную работу студента Кобзарева Андрея Андреевича  
**Тема:** «Разработка интеллектуального ассистента для поддержки бухгалтера и менеджера (интеграция больших языковых моделей в корпоративную экосистему 1С для повышения эффективности бизнес-процессов)»

**Объем работы:** 141 страница, содержит 17 рисунков, 13 таблиц, 35 литературных источников, 7 приложений.

**Ключевые слова:** ИНТЕЛЛЕКТУАЛЬНЫЙ АССИСТЕНТ, БОЛЬШИЕ ЯЗЫКОВЫЕ МОДЕЛИ (LLM), RAG-ПОИСК, МЕТАДАННЫЕ 1С, FASTAPI, КАНБАН-ДОСКА, РОЛЕВОЙ ДОСТУП, БЕЗОПАСНОСТЬ ИНФОРМАЦИОННЫХ СИСТЕМ.

**Объект исследования:** процессы взаимодействия пользователей с прикладными объектами конфигурации 1С:УНФ (поиск, создание, анализ и контроль состояния документов и справочников).  
**Предмет исследования:** методы и технологии построения интеллектуального ассистента в 1С на основе расширений 1С, клиент-серверного обмена по HTTP, LLM, семантического RAG-поиска по метаданным, JWT-авторизации и канбан-доски.

**Цель работы:** проектирование и разработка расширения «Интеллектуальный ассистент» для 1С:УНФ, позволяющего пользователям в диалоговом режиме получать консультации, выполнять типовые действия (открытие форм, поиск документов, подготовка предзаполненных черновиков), управлять задачами через канбан-доску и работать в рамках ролевой модели доступа на основе токенов JWT.

**Решенные задачи:**
1. Проведен анализ предметной области и пользовательских сценариев на примере торгового предприятия ООО «ЛюксонДекор».
2. Разработана клиент-серверная архитектура решения, включающая расширение 1С (чат-интерфейс, обработчик whitelist-команд), промежуточное ПО (FastAPI middleware на Python) и интеграцию с LLM-моделями (GigaChat/YandexGPT).
3. Реализована гибридная технология RAG (семантический поиск и сопоставление синонимов) по метаданным базы 1С для исключения галлюцинаций ИИ-модели.
4. Разработан модуль авторизации с ролевым доступом (admin, manager, employee) и встроенный сервис канбан-доски для контроля задач в контуре 1С.
5. Проведена оптимизация алгоритмов взаиморасчетов и остатков товаров (включая устранение ошибок виртуальных таблиц остатков и знаков дебета/кредита).

**Практическая значимость:** создан готовый к внедрению прототип расширения, который интегрируется без изменения типовой конфигурации. Внедрение ассистента позволяет снизить нагрузку на поддержку на 40-50%, сократить время выполнения типовых операций на 60-70%, уменьшить количество ошибок ввода данных на 75% и ускорить адаптацию новых сотрудников в 2 раза. Решение полностью совместимо с мобильным клиентом «1С:Предприятие».

## ABSTRACT
on the graduation thesis of Andrey A. Kobzarev  
**Title:** "Development of an intelligent assistant to support accountants and managers (integration of large language models into the 1C corporate ecosystem to improve business process efficiency)"

**Volume:** 141 pages, 17 figures, 13 tables, 35 references, 7 appendices.

**Keywords:** INTELLIGENT ASSISTANT, LARGE LANGUAGE MODELS (LLM), RAG SEARCH, 1C METADATA, FASTAPI, KANBAN BOARD, ROLE-BASED ACCESS CONTROL, INFORMATION SYSTEM SECURITY.

**Object of research:** user interaction processes with applied objects of 1C:UNF configuration (search, creation, analysis, and state control of documents and directories).  
**Subject of research:** methods and technologies of building an intelligent assistant in 1C based on 1C extensions, HTTP-based client-server exchange, LLM, semantic RAG search over metadata, JWT authorization, and a Kanban board.

**Purpose of the work:** to design and develop the "Intelligent Assistant" extension for 1C:UNF, allowing users to interactively receive consultations, perform routine operations (opening forms, searching documents, preparing pre-filled drafts), manage tasks via a Kanban board, and operate within a JWT-based role model.

**Tasks completed:**
1. Conducted an analysis of the subject area and user scenarios using the decorative materials trading enterprise LuxonDecor LLC as a case study.
2. Developed a client-server architecture consisting of a 1C extension (chat interface, whitelist command dispatcher), Python-based FastAPI middleware, and LLM integrations (GigaChat/YandexGPT).
3. Implemented a hybrid RAG pipeline (semantic search and synonym mapping) over 1C metadata to prevent AI hallucinations.
4. Developed an authorization module with role-based access control (admin, manager, employee) and an integrated Kanban task service.
5. Optimized debt calculation and warehouse stock retrieval algorithms (resolving virtual table syntax errors and credit/debit sign issues).

**Practical significance:** a production-ready extension prototype has been developed that integrates seamlessly without modifying the target 1C configuration. Assistant deployment reduces support desk load by 40-50%, routine operation execution time by 60-70%, data entry error rate by 75%, and speeds up new employee onboarding by 2x. The solution is fully compatible with the mobile client of the "1C:Enterprise" platform.
