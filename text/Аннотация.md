# АННОТАЦИЯ / ABSTRACT

## АННОТАЦИЯ

на выпускную квалификационную работу студента Кобзарева Андрея Андреевича  
**Тема:** «Интеллектуальный ассистент и омниканальный интеграционный слой для типовой конфигурации „1С:Управление нашей фирмой 3.0“»

**Ключевые слова:** ИНТЕЛЛЕКТУАЛЬНЫЙ АССИСТЕНТ, БОЛЬШИЕ ЯЗЫКОВЫЕ МОДЕЛИ, МЕТАДАННЫЕ 1С, RAG-ПОИСК, FASTAPI, КАНБАН-ДОСКА, RBAC, ACTION WHITELIST, АВТОНОМНЫЙ РЕЖИМ, АВТОМАТИЧЕСКОЕ ТЕСТИРОВАНИЕ.

**Объект исследования:** процессы взаимодействия пользователей с прикладными объектами типовой конфигурации «1С:Управление нашей фирмой 3.0»: навигация, подготовка документов, получение аналитических сведений и управление задачами.  
**Предмет исследования:** архитектура интеллектуального ассистента на основе расширений 1С, middleware на FastAPI, поиска по локальным метаданным и контролируемого исполнения действий.

**Цель работы:** спроектировать и реализовать учебный прототип интеллектуального ассистента для 1С:УНФ 3.0, который сохраняет типовую конфигурацию на поддержке, разделяет диалоговую обработку и учетную логику и ограничивает исполняемые команды белым списком.

**Основные результаты:**

1. Спроектирована трехуровневая схема взаимодействия: расширение 1С, FastAPI middleware и настраиваемый провайдер LLM с детерминированным резервным режимом.
2. Реализованы JWT-аутентификация, семь ролей RBAC, валидация структурированного ответа и белый список действий, исполняемых на стороне 1С.
3. Реализован поиск по метаданным: локальные эмбеддинги MiniLM в файле `.npy` при наличии зависимости и резервное сопоставление по словам.
4. Реализованы чат, канбан-доска, интеграционные маршруты и набор демонстрационных бизнес-сервисов. Их рекомендации не заменяют бухгалтерскую, юридическую или комплаенс-проверку специалистом.
5. Полный прогон 8 сентября 2026 года завершился результатом 67 успешно пройденных тестов pytest. Стресс-отчет от 6 сентября 2026 года подтвердил работу `/health`, RAG и конкурентных операций SQLite, но выявил 33 ошибки из 50 событий омниканального burst-теста; VK и email требуют доработки.

**Практическая значимость:** исходный код и тесты демонстрируют применимость предложенной архитектуры для учебного стенда. Перед промышленным внедрением необходимы сборка и загрузка расширения в целевую базу 1С, испытания реальных пользовательских сценариев, настройка безопасности и повторные нагрузочные измерения.

## ABSTRACT

on the graduation thesis of Andrey A. Kobzarev  
**Title:** “Intelligent Assistant and Omnichannel Integration Layer for the Standard 1C:Small Business Management 3.0 Configuration”

**Keywords:** INTELLIGENT ASSISTANT, LARGE LANGUAGE MODELS, 1C METADATA, RAG SEARCH, FASTAPI, KANBAN BOARD, RBAC, ACTION WHITELIST, OFFLINE FALLBACK, AUTOMATED TESTING.

**Object of research:** user workflows involving applied objects of the standard 1C:Small Business Management 3.0 configuration, including navigation, document preparation, analytical queries, and task management.  
**Subject of research:** an intelligent-assistant architecture based on 1C extensions, FastAPI middleware, local metadata retrieval, and controlled action execution.

**Purpose:** to design and implement an educational prototype of an intelligent assistant for 1C:UNF 3.0 that keeps the standard configuration supported, separates conversational processing from accounting logic, and restricts executable commands to an allowlist.

**Main results:**

1. A three-tier interaction model was designed: a 1C extension, FastAPI middleware, and a configurable LLM provider with a deterministic fallback mode.
2. JWT authentication, seven RBAC roles, structured-output validation, and an action allowlist executed on the 1C side were implemented.
3. Metadata retrieval uses local MiniLM embeddings stored in a `.npy` file when the optional dependency is available and a word-overlap fallback otherwise.
4. The prototype includes chat, a Kanban board, integration routes, and demonstration business services. Their output does not replace professional accounting, legal, or compliance review.
5. The complete test run on 8 September 2026 passed all 67 pytest tests. A stress report dated 6 September 2026 confirmed `/health`, RAG, and concurrent SQLite operation, while the omnichannel burst produced 33 failures out of 50 events; VK and email require further work.

**Practical significance:** the source code and tests demonstrate the proposed architecture on an educational stand. Production adoption requires building and loading the extension into the target 1C database, executing live user scenarios, hardening security, and repeating load measurements.
